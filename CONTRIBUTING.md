# Contributing to LectureFlow

Please read [AGENTS.md](AGENTS.md), [the development guide](docs/DEVELOPMENT.md),
and [the license scope](NOTICE.md) before changing the project.

Submit original code that you have the right to contribute under GPL-3.0-only.
State the origin and license of any copied or adapted third-party code and retain
its notices. Do not add recordings, course materials, transcripts, private paths,
credentials, model weights, or generated build outputs to the repository.

For new contributions, explicitly confirm in the PR that you have the necessary
rights and offer your contribution under GPL-3.0-only. This is not a copyright
assignment and does not change an external dependency's license. Contributions
submitted before adoption of this policy require their author's confirmation
before incorporation. No blanket right is inferred from an open pull request.

Run the checks in the development guide and include relevant behavior tests.
Binary distribution has additional source, notice, model, and media requirements;
see [the release checklist](docs/licenses/RELEASE-CHECKLIST.md).
