### 打开就用

1. 下载解压，将 **LectureFlow.app** 拖到“应用程序”。
2. 新建课程 → 开始新 Lecture，或导入已有录音。
3. 可选导入课程资料；用悬浮字幕听课，在转写页整理结果。

录音、识别、翻译与课件解析均在本机完成。已移除云端笔记与 API。首次约 1.86 GB 模型可后台下载并暂停继续。

<sub>体验版：效果、延迟、续航与长时评估暂缓。时间戳约 30 秒区间。[安装与限制 →](docs/USER_GUIDE.md)</sub>

### 本机从源码试用

```bash
zsh scripts/setup
zsh scripts/dev          # 或 scripts/build-app 生成预览包
```

详见 [开发与构建](docs/DEVELOPMENT.md)。测试使用隔离资料库，不会自动清空本机资料。
