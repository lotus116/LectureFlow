# LectureFlow 0.6.6 · macOS

macOS 端更新了课程侧栏和录音卡：可调整课程栏宽度，录音波形反映输入电平，悬浮字幕可以从侧栏打开。保留原音保存与字幕推理分离。

- 音频导入：拒绝缺少实际数据的 WAV；批量导入失败不留下空讲次；新建时避开仍可恢复的默认名称。
- 课后：单段转写采用所选讲话语言。可用键盘打开复核、回听、接受、忽略和撤销。
- 实时字幕：当本次采集明确保存了原音和双语、原音完整且当前设置仍允许时，重开可补回因后台中断漏写的首条中文。不重复修订，不覆盖人工编辑，不附加录音留存。
- 可访问性：列表与显示滑块名称更明确；显示设置支持键盘调整字号和背景透明度。

本地 Apple Silicon 审查版已验证正常重开、Finder 拖放、键盘复核及用合成音频复现的中断补译。真实麦克风、VoiceOver 朗读、外接投影及长课续航不在本轮验收范围。0.6.6 面向 Apple Silicon Mac。候选安装包已在本机验证，公开安装包仍为 0.6.5。此次发布的剩余条件见[当前状态](STATUS.md)。Windows 仍使用 [0.6.5](https://github.com/lotus116/LectureFlow/releases/tag/v0.6.5)，不需要更新。

升级前结束录音并等待保存完成。具体平台附件、签名、校验和与包内构建信息以最终发布产物为准。
