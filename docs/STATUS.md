# 当前状态 · 2026-10-30

基线：PRD V1.4。已有 macOS 离线原型和实时基础实验版；Phase 0 质量与长时实时验收仍未关闭。

## 当前可用

- 原生课程/课堂导航与创建，真实资料文件夹和 SQLite 索引。
- M4A/MP3/WAV/FLAC 批量导入受管副本；拖动排序、单段或整堂处理。
- 两种本地 ASR 候选、本地中文翻译、跨处理区间的有界前文。
- 持久化检查点、后台暂停/恢复/取消/失败重试、单 worker 互斥。
- 独立转写版本、排序后旧版本过期提示、搜索与复制。
- Markdown、TXT、SRT、JSON 和总结 Prompt 导出。
- 简洁安装/启动脚本与固定依赖；GitHub 自动检查配置。
- 实验性 AVAudioEngine 采集、三个独立开关、约五分钟 CAF 分块和录音恢复。
- 实时流式字幕、最近三段语音有限修订、增量保存与历史查看；只翻译时不保存英文或原音频。
- 实时处理与离线任务共享模型锁；字幕输入缓冲有界，录音不等待模型。

## 已完成的验证

- Apple M5、16GB、macOS 27 上运行本地模型。
- 同一短片段的 0.6B/1.7B、有/无实验术语四组对照，以及真实节奏流式短测。
- 约 175.88 分钟的三段真实录音全部完成：353 个处理区间，时间轴连续，源片段和源时间可追溯。
- 完整批处理的 MLX 活跃内存采样由约 1.8512GB 到 1.8516GB，峰值约 2.23GB；不等同三小时实时录音/续航测试。
- 原生界面中验证暂停、恢复、关闭窗口继续处理、重新打开查看和文本搜索。
- 三份源录音 SHA-256 保持不变。
- 代码检查、49 项 Python 测试、7 项原生测试、无模型的独立环境测试和原生构建通过。
- 新实时协议的双语与只翻译模式各回放 30 秒课堂音频：均生成 10 条字幕、无队列丢包；只翻译时未保存音频和英文。

原始音频、完整转写、基准 JSON 和运行记录仅保存在本地被忽略的资料/报告目录。
