# LectureFlow 0.6.4 · 复习书签与字幕修复

这次小更新让听不懂的位置可以留下复习书签，并修复悬浮字幕空白提示残留和中文回改混入相邻段落的问题。

## 更新内容

- **复习书签：** 主窗与浮窗的“标记当前”共享状态；未标记的行内书签默认隐藏，已标记显示蓝色实心。课后可按时间查看对应文字、有原音时回听，支持已复习、移除及恢复。暂停继续后仍按原音时间映射定位。
- **悬浮字幕：** 有字幕后不再残留“等待讲话”等空白提示；新字幕即使与上一段修订号相同，也能触发最新内容跟随。
- **中文回改：** 明确分开当前目标段与相邻参考，拒绝可识别的串段输出并保留待办；流式初译、前两段必做上下文回改及积压后补做继续保留。
- **实验性口音复核：** 独立开关默认关闭，保留原始识别及候选记录。目前没有准确率提升证据，开启可能增加计算负载；老师追踪和人声分离尚未集成。

## 安装与更新

适用于 Apple Silicon、macOS 26+，建议至少 16 GB 内存。下载 `LectureFlow-0.6.4-macOS-arm64.zip`，解压后将 `LectureFlow.app` 放入“应用程序”。更新前结束采集并完全退出旧版和测试版，保留已有资料库与模型。

安装包包含独立 Python，无需另装 Python 或 Xcode；不含模型权重、私人录音或课件。首次准备模型需联网，课堂处理在本机完成。发布页附 `SHA256SUMS`，包内 `build-info.json` 标明来源提交及版本，便于核对实际运行的应用。

应用使用本地签名，尚未 Apple 公证；若系统阻止打开，请核对来源并按系统提示处理。

## 验证与限制

- 功能基线已通过 183 项 Python、42 项原生测试及 4 类退出检查；发布工作流会对本次版本重新执行检查、独立打包、签名验证和包内后端启动检查。
- 字幕修复有动态合成复现及像素渲染回归；完整开发应用验证了书签默认隐藏和主窗／浮窗标记、取消联动。悬停显现尚未取得可靠自动化视觉证据，不宣称全部交互验收。
- 中文回改已知串段反例改善不等于整体翻译准确率通过；短句补全、专业词、重口音及重叠讲话仍可能出错。
- 真实麦克风持续运行、三小时负载、续航与硬件异常未在本轮验收。正常退出保存不等于强杀后的全链路恢复；旧录音缺少暂停映射时不猜测书签回听位置。

已有录音、人工修改和历史结果保留；不会自动整堂重跑。详细验证及剩余问题见 [STATUS](https://github.com/lotus116/LectureFlow/blob/main/docs/STATUS.md)。
