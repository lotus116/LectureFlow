# 0.4 课堂流程与识别污染修复

对应 LF-02、03、04、05、06、08、09、11、12。以本轮真实使用反馈修订实现，不将功能检查当作准确率或长时验收。

| 问题 | 本轮产品行为 |
|---|---|
| 课件词成批进入转写 | 生产实时/离线识别只接收音频，不传整张词表、课件或历史文本；旧任务恢复也遵守新策略。翻译只获得原句确实出现的少量已采用术语；原识别不强制替换。 |
| 课堂操作像功能开关面板 | 单一主按钮控制开始、暂停、继续；另一个按钮保存并结束。三种记录方式为录音与双语、仅录音、仅字幕；独立开关保留在更多选项。 |
| 暂停后重开全部功能 | 继续原方式，保持同一堂课；暂停时间不计入录音计时。结束后再开始为新的一次采集，资料仍在当前课堂。 |
| 模型未就绪阻止录音 | 明确选择保存录音时可先录音，模型就绪后再开字幕；仅字幕模式不擅自打开录音保存。 |
| 模型按键失效 | 独立可见模型面板，区分可切换、需下载、等待语音边界、正在加载、实际生效；录音写入持续独立。 |
| 侧栏按钮移动 | 统一管理分栏与固定导航按钮，避免系统重新插入或移动自己的切换项。 |
| 后台任务难找、错误反复弹窗 | 所有课程的后台任务统一入口，可全部暂停；刷新错误就地提示，用户决定重试。 |
| 结束后不知道去哪里 | 显示封存/入库状态与查看录音、课后转写入口；不自动发起总结请求。 |

已有被污染版本保留，不静默改写；提示从原音重新转写并保留历史。没有原始录音的仅字幕记录，不能凭词表可靠还原遗漏原话。

验证重点：带旧词表的恢复任务不得把词表传入 ASR；原文涉及的真实术语仍保留；暂停/继续、结束、重启恢复、权限等待取消与隐私组合行为测试；模型菜单和侧栏位置检查。效果、时延、续航与三小时评估继续暂缓。

已通过 89 项 Python 与 19 项原生行为测试；新增启动期间改选模型、切回原模型与延迟确认的状态检查；合成资料界面中验证模型选择、记录方式选择和侧栏按钮隐藏前后位置。尚未将真实麦克风、跨全屏所有组合或模型精度当作验收通过。

0.4.1 布局回归修复：分栏替换后，内容较少的转写/实时/笔记页会让父容器居中，使顶部控制向下移动。外层详情、课堂容器和内容区域均固定顶端对齐，内容区域占满剩余高度；按五个页签分别检查空内容与已有内容场景。

按用户最新发布节奏要求，本轮热修复仅提交推送并提供已构建预览包，不额外正式发版。版本号变动不再自动触发发布，保留手动交付入口；完成本轮收尾后停止。
