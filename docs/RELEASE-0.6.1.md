# LectureFlow 0.6.1 · 阶段体验版

把本轮简化课堂流程、原生界面调整与课程术语质量修复合并为一个可安装版本。面向 Apple Silicon Mac，要求 macOS 26+，建议至少 16 GB 内存。

## 这一版可以做什么

- 以课程组织 Lecture；一键创建并开始采集，也可导入已有录音。
- 三种记录方式：录音与双语字幕、仅录音、仅字幕；暂停后继续，结束后可追加录制。
- 同一转写页查看实时记录和课后结果；支持逐段编辑、显式重新翻译，以及 TXT、Markdown、SRT、JSON 导出。
- 每门课程统一管理 PDF/PPT，所有 Lecture 共享资料与辅助术语。
- 悬浮字幕置顶，中文为主；后台任务可暂停、继续、取消和失败重试。
- 界面收敛为课程主页、录音与转写，包含暖白绿配色、窗口比例及更多菜单的整理。

## 本次重点：修复词表污染通道

- 自动英文拼写提示与中文译名分开处理。自动中文仅为建议，只有课件明确中英对照或人工校正才用于翻译。
- 收紧候选提取和 ASR 软匹配；拒收整句解释、原文回填和格式异常；代码名及不明缩写可保留英文。
- 修复单段重新翻译传入整份词表的问题；资料译名冲突时不自动采用。
- 打开课程资料会用缓存文字重建旧派生词表，保留人工修改、停用记录和历史转写，无需重新导入。旧结果不会自动覆盖，可主动生成新版本。

本版本不再提供笔记、总结 Prompt 或云端总结 API。录音、识别、翻译与资料解析在本机完成。

## 下载与安装

下载附件 **LectureFlow-0.6.1-macOS-arm64.zip**，解压后将 **LectureFlow.app** 拖入“应用程序”。安装包包含独立运行环境，无需 Python 或 Xcode；默认不内置模型，首次准备约 1.86 GB 模型，支持暂停和继续。附件 `SHA256SUMS` 用于核对下载完整性。

更新前结束录制并完全退出旧版，再替换应用。已有源文件与转写不自动删除；自动生成的旧术语译名会按新规则重新整理。

应用使用本地签名，尚未经过 Apple 公证。若 macOS 阻止打开，在核对下载来源后按系统“隐私与安全性”提示允许打开，无需关闭系统安全保护。

## 验证与已知限制

- 发布验证：ruff 通过、107 项 Python 测试、19 项原生测试；[发布工作流](https://github.com/lotus116/LectureFlow/actions/runs/41171342807) 已完成独立打包、签名及后端检查。下载后的 ZIP 与发布校验文件一致。
- 本机三个合成术语短测中，“Memory Protection”“Ransomware”输出短译名；“DLL”原文回填被拒收。这不是完整课堂准确率或增益评测。
- 模型准确率、翻译质量、延迟、续航与三小时稳定性评估仍暂缓，未验收通过。
- 离线字幕时间戳约为 30 秒处理区间，尚非逐句精确对齐。
- 真实麦克风、设备切换、睡眠、首次权限与多尺寸界面仍需实际使用反馈；复杂课件解析和专业词译名仍可能有误。
