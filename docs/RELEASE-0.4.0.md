# LectureFlow 0.4.0 · 课堂操作与识别修复

- **修复词表混入转写**：实时、离线及旧任务恢复均只把音频交给识别模型；不再传整张课件词表、课件全文或历史文本。翻译只匹配当前原句涉及的少量已采用术语。
- **像录音软件一样操作**：一个主按钮开始、暂停和继续，一个停止按钮保存并结束；计时排除暂停时间，继续记住记录方式。
- **三种记录方式**：录音与双语、仅录音、仅字幕；高级独立开关移入设置。模型未就绪时可先保存录音，仅字幕模式不会擅自保存音频。
- **修复模型切换交互**：明确可切换、需下载、等待语音边界、加载中和实际生效状态。
- **固定侧栏按钮**：隐藏、展开后仍在左上角；增加所有课程的后台任务入口、全部暂停、保存反馈与空课堂引导。

旧转写保留。使用过旧词表提示的版本会显示重新转写入口，新结果作为独立版本保存。没有保留原音的仅字幕记录不能可靠还原遗漏原话。

Apple Silicon · macOS 26+ · 建议 16 GB 内存。更新前暂停并退出旧版，再替换应用；已有资料和模型继续使用。运行环境随包附带，模型首次后台下载，不内置于安装包。

已检查功能、构建和数据保护；模型准确率、延迟、续航与三小时连续采集仍待使用反馈，未标为通过。当前构建使用本地签名，尚未 Apple 公证。
