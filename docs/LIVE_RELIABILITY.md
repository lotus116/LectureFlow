# 实时字幕算法与验证边界

## 设计

- 音频保存继续由原生采集独立执行。识别和翻译共用单一推理线程，避免 MLX 并发访问。
- 恢复依据输入与处理音频时间、进度事件和推理耗时。文字相同、静音、重复或结巴本身均不触发恢复。正常静音也产生音频处理进度。
- 单次无进度期限至少 180 秒，随已完成推理耗时自适应。每次采集最多恢复三次，退避 2、4、8 秒；失败进程终止后才恢复字幕。缺口写入本地诊断，原始录音独立保存。
- 内部识别保留 12 秒上限。低能量检测使用有上下限的噪声估计与迟滞，句末与未完整短句采用不同停顿期限。保留前置音频与尾部静音。
- 阅读段落由连续、未完整的短片段拼接，只拼接原文并保留各片段时间映射与原始修订。限定段落时长与片段数，遇到缺口或结束立即收尾。
- 临时翻译合并为最新请求，稳定片段先保存原文，翻译待办有界且按序完成。积压时暂停前文重译与课件增强。队列达到上限时先处理最早稳定翻译，输入音频过载缺口明确记录。
- 课堂反馈修正后，新任务默认保存固定英语模式，旧任务缺失配置时按英语恢复。纯中文原话直出，含英文的混合句交给翻译模型并要求保留中文、否定和纠正。

## 验证边界

本页记录设计，完成情况以 STATUS 和行为测试为准。能源检测无法区分老师和同学，也不能确诊此前字幕重复的原因。自动语言接口支持不等于中英混合识别质量已验收。有限超时无法证明推理永远不会超过阈值，超过期限按处理不可用记录并保留源录音供后续转写。

## 实现参数与限制

- 16 kHz 音频按约 0.25 秒输入，原生与 Python 输入队列各保留八包。过载丢弃字幕音频并计数，源录音另行保存。稳定翻译待办最多三条，满队列时先完成最早一条，结束时顺序排空。
- 能量阈值为估计噪声的三倍，限制在 0.002–0.008，语音持续阶段使用 0.7 倍迟滞。噪声估计仅在非语音阶段更新。该方法仍是能量启发式，持续背景噪声与远处人声的区分尚待真实验证。
- 完整标点后的停顿为 0.65 秒，其余为 1.25 秒，识别片段仍上限 12 秒，起始保留前一包音频。阅读层只连接同会话、间距不超过 0.35 秒的未完整短片段，最多三片段、总长 12 秒。原始修订、源区间与导出记录逐片段保留。
- 临时译文只处理最新原文，完整句至少间隔两秒，其余以六秒作为调度期限。稳定译文优先，在积压超过两包时等待，最迟六秒后获得调度机会。期限约束排队，实际模型推理耗时仍会增加等待。前文一段重译与课件增强共享每 20 秒最多一个可选任务的预算，只在没有待处理音频时执行。
- 看门狗不观察文字是否变化。已收到音频但处理无进展超过 `min(600, max(180, 最长已完成单包处理耗时×8))` 秒时终止字幕子进程，初次准备允许 300 秒。识别器累计接收超过四秒音频而内部 chunk 计数不前进时也报告异常。上游原有重复检测与窗口保护继续使用。
- 故障恢复最多三次，退避 2、4、8 秒。恢复使用当前保存开关。达到上限后禁止自动协调再次开启字幕，用户暂停再继续可重新尝试。正常暂停／结束接收已登记旧进程的尾部字幕，新进程等待旧链路收尾；故障进程事件隔离。
- `Logs/live-health.json` 保存最新数值快照及当前会话最近 64 个缺口，包含输入／处理音频时间、单包推理耗时、积压、两侧丢包与恢复标记。日志不含课堂文字或音频，模型任意 stderr 不写入应用日志。历史缺口超过上限会被滚动替换。
- 稳定原文先落库，再完成翻译。进程被终止时少量待译片段可能仍未完成，界面明确提示；已有原文遵循保存开关保留。仅字幕且未保存音频时，无法从源录音补齐缺口。
- 新会话／版本默认英语，保存 `source_language` 与 `language_policy=2`。旧会话／版本缺失配置时仍按英语处理。自动模式每个识别片段交给上游检测，不按临时文字在应用层反复切换语言。实时 JSON 导出包含会话语言配置。

## 开放语言检测回归修复 · 2026-11-04

此前把 `language=None` 的开放语言检测标为“自动识别中英”并设为默认，未实施中英候选限制。重口音英语可被判为粤语或其他语言，错误原文继续进入翻译链路。此前的八秒英语回放没有覆盖这种失败场景，不能支持自动模式作为课堂默认。

本次恢复固定英语默认，覆盖原生新会话、课后任务和 CLI。偏好改用版本化键；旧版自动设置不能证明用户主动选择了准确标注的开放实验功能，因此一次性迁移为英语。新版明确选择的实验模式可以保留。既有会话／转写版本的配置与原始内容保持可追溯，更新语言通过新会话或新转写版本生效。

从用户指出的课堂原音提取三个片段，共 33 秒，用同一 1.7B 模型和相同流式参数对照。自动模式分别检测为粤语、中文、粤语；固定英语均输出英语，样本中的中文混入消失。仍存在英文错词，未以语言标签或文字脚本正确替代语义准确率验收。源录音校验通过，对照文字和音频仅存本机临时目录。
