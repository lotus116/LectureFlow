## 从课堂入口实际验证

| 情况 | 候选结果 |
|---|---|
| 录制中向上翻阅 | 从课程主页点击开课，确认进入实时记录。用十条合成英文撑开字幕区，通过 Page Up 进入阅读模式，将视口置于 30 点。设置中切为墨绿再恢复冰蓝，旧段迟到的中文更新到同一 ID，英文和十段数量保持，阅读偏移仍是 30 点，录音计时前进。 |
| 真实翻译阻塞 | 独立 AppKit 测试副本用合成语音替代麦克风，保留实际开课控件、写盘、进程通信、SQLite、本机 ASR 和翻译模型。首次翻译注入 7 秒等待，英文先出现，等待期间实际经过设置选择墨绿及恢复冰蓝，计时继续。控制器在该窗口内收到 7 次不同英文更新，随后同一 ID 收到中文。这里统计的是控制器可见的更新，未逐帧测量屏幕。 |
| 原音及收尾 | 该次回放暂停、继续、结束后只登记一段 25.00 秒录音，有两段采集时间映射。解码封存 CAF 后，完整 12 秒讲话的 192,000 个采样逐个匹配，起点在第 48,000 个采样偏移。最终数据库保留两条已锁定的双语字幕。 |
| 设置重启 | 实际设置控件写入墨绿，结束预览并另起进程后读回墨绿，再恢复冰蓝。 |
| 课后优先复核 | 从实时记录的更多菜单进入复核比较；核验定界试听和 Esc 关闭后停播。对同一候选接受、撤销、忽略、再撤销，SQLite 留有五次状态（含初始状态）。最终逐字核对实时英文等于原稿，候选与原稿分别保留。 |
| 浮窗 | 合成事件验证中文晚到、56 点字号、320 点宽和最低透明度；注入减少动态分支时手动阅读偏移为 20→20。应用内关键窗口保持。外部应用焦点及真实显示效果待实测。 |

最初的真实模型探针在预先选中的讲次页寻找课程主页按钮，因此未开始采集。改为从空课程主页实际点击开课后，上述整链回放通过。所有课堂输入均为合成资料。远端 CI、真实长课质量、长时热状态／续航、硬件故障及跨平台实机均不在此次通过范围。
