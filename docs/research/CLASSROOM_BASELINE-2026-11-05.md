关联SD-03/04/05/08、LF-03/04/06/11。承接[公开人工参考归因](ACCENT_DIAGNOSIS-2026-11-05.md)，本轮按授权只研究已有课堂录音、既有本地模型和课件；不修改App、模型配置或默认值，不打包、发版。基线提交d0c2815。[推理前协议及资格修正](CLASSROOM_BASELINE_PROTOCOL-2026-11-05.md)保留原记录。

## 结论与优先级

**没有证据可以把当前问题统一归因于口音，也没有通过课堂准确率验收的增强方案。** 本轮发现一个可以不依赖逐字稿核实的问题：中文上下文回改会把相邻字幕内容翻译到当前目标中。原始流式基线已有该问题，长原音候选的回改又出现两处明确实例。原音窗口有可能改善领域词和句意，但同时改变否定、数字单位及动作方向；资料提示确实影响识别，也可能引入领域偏置和重复退化。

**唯一优先建议：下一轮先离线修复并验证中文回改的目标隔离与失败保护，保留前两段必做回改。** 这是本轮可明确核对的错误链条，不能靠增加ASR计算解决。不直接启用长窗口自动覆盖，不放宽口音接受门；这些行为修改尚未实施。

此前公共人工参考已经给出量化依据：新说话人留出986词，原接受门135→135错词，完整窗口135→126，但6/20段退化，局部一致规则变成139。现有门无收益，不仅因为保守：候选本身也有害，评分和一致性不能可靠选中好修改。本轮课堂结果与这种不稳定性相符，不能把公共数据收益换算成本老师收益。

## 样本、控制与完整性

- 主实验R、E各连续5分钟，共10分钟、50条稳定字幕。两段属于同课程的不同录音；未核实说话人身份，不能声称跨老师验证。R与旧短样本重叠30秒，E避开旧范围。
- 12个预定25秒核心，每个按中点选一条完整稳定字幕作为对照目标；另8个机械信号诊断、4个低信号保护候选。后两类不是随机样本，保护候选也不是已知正确文本。24个目标全覆盖。
- 诊断选择以消融前冻结脚本为准：中文字符信号权重3、少于4个英语词权重2、相邻重复词计数，再按时间打破平局；没有实际使用协议概述中提到的首稳定至最终英文变化量。此差异不改变12个预定核心，不应将诊断组描述为覆盖全部高风险类型。
- 7种方法×24，加4个低相关资料控制，共172条方法记录；ASR及中文初译／回改均无截断标志。相同输入复用结果，172不是172次独立模型运行。
- A保留流式过程；A-text固定其英文重新翻译；A-batch同边界无提示；B0/B5为最多30秒连续原音，分别不借未来／最多借5秒后文；C同边界加自动提示；D0/D5为B加同一提示；U为4个低相关提示控制。
- 对目标的英文投影使用文字对齐，保留完整窗口、对齐操作和不确定标记。B5/D5可能把未来尾句带入目标，不能当作精确声学对齐；投影还可能漏末尾闭引号，涉及该情况的中文问题不作主要无条件证据。没有按结果修剪或丢弃失败样本。
- 候选翻译初译固定前两段、回改固定前后各两段。回改使用的后两段可能晚于5秒到达，因此不是“5秒内最终中文”的实验。
- 未获得可据以声称听懂音频的听音验证，也没有课堂人工逐字参考；不报告课堂WER、已纠正数量或语义改善率。不用其他模型输出、课件或多数一致作真值。

原计划N的5分钟先导中，25条ASR结果有19条含中文，不能作为本轮英语留出；替换E前已冻结资格修正。N另有CPU检索预检查干扰计时，保留但不并入英语性能。N隔离复跑中止，不算完成测试。N最终中文有2条输出内部上下文提示标记，单列诊断；主实验R/E无该字面标记，但仍有内容越界，不能只用标记过滤保证安全。

尾延迟为首次对应事件墙钟减当时事件音频结束时间；首中文可来自临时字幕，不能与首稳定英文当作相同成熟度，更不等于从讲话开始等待这些秒数。两组稳定字幕均为12秒目标。输入覆盖完整300秒只说明没有音频时间缺口，不能证明没有漏词。只有单次回放，内容和系统负载影响未分离。

固定12目标的单次额外ASR平均：同边界1.535秒，B0为2.163秒，B5为2.591秒；B5还要等待最多5秒原音。24目标实际额外ASR合计276.99秒，MT增量合计160.37秒。MT按目标／上下文缓存，不能拿各方法增量时间当独立速度比较；这些批处理计算也不是已验证的在线新增延迟。

自动相关提示检索24次合计40.94秒，平均1.706秒，最大2.741秒；不含U控制的额外扫描。研究只给纯函数增加有界缓存，未改返回值或App；不能用该计时宣称现有App检索已经优化。运行峰值RSS分别约0.77GB（R与N先导同进程）、1.05GB（E）、1.18GB（消融）；对应MLX峰值约3.60／3.55／3.69GB，二者不能相加。系统此前已有约6.46GB交换占用，不能将其归因于本轮。未测长课热状态、续航或三小时负载。

## 逐类归因与反例

详细逐字证据、课件页、源时间和可回听音频全部留本机；下表仅匿名事实摘要，不公开课堂原话。

| 归因 | 证据与能下的结论 |
|---|---|
| a 声学替换／口音 | E-4等长原音出现更连贯候选，尚未听核；无法从错词形态分离口音、发音、噪声和语言模型偏置，不能确定口音为主因 |
| b 术语 | R-protect2有领域词候选，R-1有资料诱导风险；自动检索会从错误首稿出发，课程相关不等于当前语境相关 |
| c 切分／遗漏／归属 | 主基线输入没有时间缺口；B0固定核心5/12、B5为11/12有投影不确定性。不能把更长文本直接替换当前字幕 |
| d 原音上下文 | R-protect2与E-4是两个不相邻的可能收益案例；E-2动作方向、R-5数字单位／否定互相冲突，没有可验证净收益 |
| e 重叠／混响 | 本轮无听音或源分离参考，无法判断；不据此推进老师追踪或分离 |
| f 中文翻译 | E-hard4原流式基线及A-text回改加入后文内容；R-1、R-6的B0初译尚对应当前目标，回改却翻译后两段。可核实的是相对输入英文的目标范围违约，未证明英文与原音完全正确 |
| g 队列／未更新 | 两个5分钟均零丢包、回改完成、待办清零；本次结果不能归因于任务一直没执行，不代表长期或强杀恢复已通过 |
| h 证据不足 | 没有课堂逐字真值、已知正确保护集、当前课件页、说话人身份或重复运行；不计算错误占比或把疑似收益当通过 |

R-protect1亦有邻段污染，但其投影闭引号不完整，单列为可能受研究输入影响，不与上述三个实例混为同等证据。没有逐项穷尽语义标注，这些例子不能作为错误率分子。相同候选复用的四个方法也不能计作四次独立失败。

## 下一步的具体范围与验收建议

建议只开展“中文回改目标隔离”离线修复：让当前目标与参考上下文明确分隔，验证结构化目标边界、上下文长度和输出约束；检测提示泄漏、邻段复制和异常重复。简单正则只能覆盖一部分，不能把没有触发规则当正确。

复用此次已冻结反例作为开发回归，另留未见目标验证。比较初译与回改相对同一英文输入的忠实度、上下文消歧收益，以及邻段复制、否定／数字／逻辑变化；不得用模型自评代替正确性。不合格回改保留已有译文和失败状态，研究重试／补做，不能静默删除必做回改，也不能用关闭回改换性能。保护、补做和任何接受规则均须先明确实现范围，再改变App。

ASR下一轮若继续，方向仍是有界连续原音＋可靠的字幕归属和防漏词验证；此前公开人工参考的完整窗口小幅收益仍值得保留，但本轮没有产生可上线的选择器。当前质量门未通过，故未进入候选3分钟实时原型；原因是没有可核实净质量收益，不是为了节省额度。老师追踪、分离、资料重设计不在本轮实现；pin“不懂处”仅记录为待确认候选，不等于窗口置顶。
