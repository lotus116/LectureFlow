# 口音增强实验构建 · 2026-11-05

对应 SD-04/05/08、LF-03/04/11。用户后续明确批准实施、真实录音对照、审查修复、同步文档、提交推送及本地测试包，禁止正式发布。老师追踪、人声分离、资料增强重设计不在本次范围。

## 实现与接受门

[实时设计](../design/REALTIME.md)记录调度与参数；[使用指南](../USER_GUIDE.md)记录开关位置。只增加口音增强独立持久化开关，默认关闭，暂停后切换；保留原首稿、固定英语和必做中文上下文回改。

原音与相邻片段解码、词级对齐、目标原音独立解码和原音／静音假设评分共同限制接受。两次模型一致、通顺、术语命中均不足以单独通过。评分不是准确率，阈值未校准；对插删、跨界、数字／否定／已列举单位及大改写拒绝。源版本与普通修订号分开，接受英文后重排匹配新英文的中文任务；原识别及历史不覆盖。

独立FIFO、最老等待时间、最近三段原音缓存、退役前复核与退出排空有行为测试。模型仍串行且不可抢占，缓存有界不代表持续算力不足仍能实时。失败保存为failed，不能计作成功完成。录音恢复命令只从已封存原文件读取，并只写过期候选审计；不是A01b自动全链路恢复。仅字幕不新增录音，进程退出失去内存原音。

## 资料与实验口径

- 本机已有 RM A（原投诉来源）的原音；使用30秒起的连续180秒。31个原始文件哈希核对。私人逐字转写、候选、时间定位和原音只在本机报告目录，不入Git。
- [EdAcc官方数据](https://huggingface.co/datasets/edinburghcstr/edacc)：18段、264秒、13名说话人。固定行范围抽取，未按模型结果选样；用validation作开发检查，不称独立留出集。口音标签粒度不一，未覆盖本课堂老师的具体口音。
- 官方人工参考中的声音事件标签从本次词错误统计移除，转小写、去标点、保留数字。这不是官方完整EdAcc评分器，也不是中文语义评分。不能把人工转写当作绝无误差或排除模型预训练见过样本。
- 公开样本检查错误数、正确内容被改坏及接受／拒绝；私人课堂没有人工真值，不报告课堂WER或“已纠正”数量。
- 真实节奏按0.25秒包输入CaptionEngine，包含ASR、临时／稳定初译、前文回改、口音复核和结束排空；注入8秒消费者停顿测试短暂过载。它不包含真实麦克风和录音磁盘故障。包内stdin协议回放另验，不能拿单次ASR速度代替整体延迟。

## 审查修复

- 标点变化不应被当作发音变化：词级对齐忽略模型标点，但应用修订保留原标点。
- 稳定英文修订清除旧中文并重新翻译；临时英文流保留原有临时中文显示行为，关闭开关不引入闪空。
- 过期翻译不提交；人工／锁定内容使旧任务失效，不在退出排空中循环重试。源版本改变则保持原等待时间重新排队。
- 同目标新任务不被旧结果覆盖；退出回执如果仍有口音待办不判定成功。
- 恢复使用包内FFmpeg，校验源哈希、capture_id和时间范围；不依赖用户PATH，不写新音频，实时任务到来时在段间让路。

## 验证状态

已完成155项Python测试；36项原生测试及4种真实AppKit隔离退出探针通过，ruff、文档完整性检查通过。新增测试包含接受路径、声学消融拒绝、敏感词拒绝、50段积压排空、开关切换、旧翻译／复核结果隔离、人工保护、保存隐私、已保存原音恢复及退出未排空保护。

公开参考：645词，关闭／开启均107词错误（本次口径约16.59%）；18段中0段改善、0段退化，自动接受1次。接受的 `also → level` 在参考相应位置仍不匹配，没有减少错误，不能称为已纠正。目标片段在同一行的5.25–14.25秒，证据留在本地。另一个 `like → and` 候选原音优势约0.047，被0.08门槛拒绝。**本轮没有证实准确率增益**，保留默认关闭，不为得到正结果而放宽门槛。没有课堂人工真值，私人候选仍待听核；测试中的原课堂60/180秒没有自动接受改写，中文没有因口音接受而变化。

## 未覆盖与使用判断

三分钟不是整节课验收；三小时、续航、热稳定、硬件故障、跨教室泛化、真实课件增益和课堂人工中文质量仍未验收。实验开关不保证准确率提升，新增复核可能增加延迟；未发现改坏不代表零风险。英文不保存时审计不保留英文候选，不能凭录音恢复该原文快照。正式版仍为0.6.3，本轮不创建发行标签或GitHub Release。
