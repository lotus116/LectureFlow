# 当前已确认产品需求

本文是当前产品行为的主要维护位置，**需求存在不等于已实现**；逐项实现、验证和缺口只在 [STATUS](STATUS.md) 维护。沿用 SD-01–SD-11、LF-01–LF-12 和 A01–A10，不重编号。

来源为[原始 PRD](archive/2026-11-05/snapshot/docs/PRD-v1.4.md)、[2026-10-31 确认设计](archive/2026-11-05/snapshot/docs/PRODUCT_DESIGN-2026-10-31.md)及后续明确批准的变更；[决定与优先级依据](design/DECISIONS.md)说明哪些旧决定已被替代。发现代码不符合本页，应记录缺口，不能把需求改成代码现状。功能行为、默认值、范围或验收变更先与用户讨论并批准。

## 1. 定位与范围

0.6.5 面向 Apple Silicon Mac 和 Windows 11 x64。两端共享课程、资料、字幕、保存边界和课后版本规则；各自的采集、模型运行环境与桌面交互见[架构](ARCHITECTURE.md)。Windows 的实验性口音复核仍待移植。

专注英语课堂的本地录音、英文转写、中文翻译和悬浮字幕。用户将一门课的 PDF/PPT 批量交给软件，软件自动维护轻量辅助术语表，供该课程所有 Lecture 使用。

- 资料可选：不导入资料也能录音、识别和翻译。
- 资料仅辅助识别与翻译，不生成课程知识图谱、长篇课程上下文或摘要。
- 移除笔记、总结 Prompt、云端总结 API、服务商与密钥设置以及相关后台任务和入口。
- 保留转写复制及 TXT、Markdown、SRT、JSON 导出。
- 用户确认目前无实际用户，不要求保留旧版笔记/API 功能或设计旧版本迁移兼容。此决定不授权删除源文件，也不放松新版自身的数据保护要求。
- 不增加云同步、使用统计自动上传或错误报告自动上传。

## 2. 信息结构与导航

```text
本地资料库
└── 课程
    ├── 课程资料：PDF/PPT、处理状态
    ├── 辅助术语：自动条目、人工调整
    └── Lecture
        ├── 录音
        └── 转写：实时记录、课后结果、人工编辑、历史版本
```

- 侧栏只保留课程 → Lecture 两层；用户界面统一使用 Lecture，移除“课堂”的混用。
- 点击课程进入课程主页，以 Lecture 列表为主，提供明显的“课程资料 · N 份”入口。
- 课程主页提供“开始新 Lecture”“新建 Lecture”“导入已有录音”。
- “开始新 Lecture”自动创建、进入并沿用上次记录方式启动采集；按钮旁显示记录方式，首次需要麦克风权限。
- “新建 Lecture”只创建，不自动采集；默认命名 Lecture 01、Lecture 02 等，日期另行显示，允许改名。
- “导入已有录音”创建 Lecture 并导入；取消文件选择不留下空记录。
- Lecture 内只有“录音”“转写”两个内容页；悬浮字幕有独立入口。
- 从 Lecture 可快捷返回所属课程资料页；不保留 Lecture 专属资料范围。
- 不增加学期、标签、收藏等层级。
- 复习书签属于当前 Lecture 的时间点，不增加导航层级；从采集控制区打开复习标记列表。

## 3. 课程资料与轻量术语表

### 3.1 文件管理

- 支持批量选择或拖入 PDF/PPT，沿用 PDF、PPTX、旧版 PPT 的本地解析及适用的本地 OCR 能力。
- 从该课程任意入口导入的资料均属于课程，所有 Lecture 自动共享。
- 移除“全部资料／本堂课／课程共享”范围选择，统一称“课程资料”；移除“知识库”名称。
- 列表展示文件名、页数和状态，支持打开原文件、重新处理和删除。
- 状态：等待处理、正在处理、已就绪、需要处理。失败说明具体原因，可重试；一个文件失败不阻塞其余文件。
- 没有模型也可先保存文件、解析文字和提取英文候选，不等待中文译法补全。
- 不要求用户为每次 Lecture 指定重点课件。

### 3.2 术语结构与生成

仅维护：英文术语或固定拼写、缩写或别名、可为空的中文译法、内部来源文件与页码。

- 重点提取专业短语、缩写、算法名、产品名、代码标识符；过滤普通词、页眉页脚与重复内容。
- 分词与词频可参与筛选，但不以出现频率作为唯一标准。
- 优先采用资料中的明确中英对照；缺失译法可由本地模型生成短译名建议，失败或不确定留空。自动建议不作为翻译约束，课件明确对照或人工校正才可用于翻译；冲突译名不自动采用。
- 不维护长定义、概念关系、课程摘要；不接 API 做批量整理。
- 默认自动合并，英文按相关性用于拼写辅助。自动中文显示为建议，不与人工/课件对照混淆；不设置强制逐词审核流程，不确定时正常翻译。
- 次级入口“查看辅助术语”支持搜索、修改英文/中文、停用、手动添加。人工修改和停用记录优先，重新解析不能覆盖。

### 3.3 增量维护与生效

- 新增文件只处理新增内容；同课程相同内容重复导入跳过。
- 修改后的文件支持作为新版替换；新结果就绪后切换，处理中继续使用上一份可用词表。
- 删除资料需确认，只删除受管副本；移除仅由该文件支持的自动术语，其他文件仍支持的保留。
- 用户手动添加或修改的术语保留，直至用户主动删除；恢复资料后自动重新整理。
- 资料更新用于后续语音片段与新建转写任务，不自动改写既有字幕或结果。
- 已启动离线任务使用创建时的词表快照，不中途换依据。
- 词表更新只提示“有新的辅助术语可用”，不把旧结果标成错误或强迫重跑。
- 资料页默认展示文件列表、辅助术语数与更新状态，不默认展开术语编辑器。

### 3.4 模型使用边界

- 根据当前语音识别结果和最近上下文选择少量相关术语，不向模型灌入整门课程的词表。
- 识别使用英文拼写、缩写等必要信息；翻译只使用当前语句涉及的英文—中文对应。
- 无相关词时走正常处理路径；不能因词表存在某词就强行改写原话。
- 保留原始识别与修订版本；临时、稳定、修订、锁定状态继续内部维护，默认有限回溯最近 1–3 句。
- 中文初译与结合后文回改是核心任务；短暂积压只延后，不丢弃。当前已批准范围为前两段随新后文回改、完成后才锁定，不能借性能优化静默削弱。
- 重处理不覆盖历史；录音写入不能等待识别、翻译或资料整理。

## 4. Lecture 采集生命周期

| 记录方式 | 保存音频 | 实时字幕 |
|---|---|---|
| 录音与双语字幕（首次默认） | 是 | 英文与中文 |
| 仅录音 | 是 | 无 |
| 仅字幕 | 否 | 默认英文与中文 |

- 记住上次记录方式，开始前明确展示；仅字幕持续显示“不保存音频”。
- 音频保存、英文保存、中文翻译的细分选项收进设置；切换记录方式或麦克风须先暂停。
- 翻译开启时内部 ASR 必须运行；英文显示和保存仍可关闭。
- 主按钮：开始 → 暂停 → 继续。暂停不清零实际采集计时，继续属于同一 Lecture。
- 单独提供“结束 Lecture”，无需确认；停止采集、保存已有内容并后台收尾，不删除 Lecture。
- 结束后提供次级“继续录制”，追加一段录音，不覆盖原有内容；仍可导入、转写和查看结果。
- 模型未就绪且允许保存音频时立即录音，显示“正在录音，字幕准备中”；模型就绪后开始后续字幕。此前音频可课后转写，不暗示已自动补齐实时内容。
- 仅字幕且模型未就绪时等待，提供“改为仅录音”，不擅自保存音频。
- 结束后不自动整堂重跑；用户点击“生成课后转写”才处理已保存录音。实时记录保留。

## 5. 转写、编辑与导出

- 同一“转写”页切换“实时记录／课后转写”，二者保持独立结果。
- 默认显示正在产生或最近查看的结果；课后完成只提示查看，不抢走用户当前阅读位置。
- 重复转写保留历史，历史入口收起，课后结果默认展示最新一份。
- 主窗口默认英文在上、中文在下，带时间标记；可切换双语／仅中文／仅英文。
- 显示语言切换不重新推理、不修改保存设置；未保存英文时不提供不存在的英文内容。
- 正在识别的尾部可更新，稳定内容正常显示，不逐句展示内部状态标签。
- 短暂停顿不因模型临时句号直接确认句界；内部识别分块与字幕句段分离，保留流式初译、必做回改和字幕长度上限。2026-11-07 用户批准实施，参数与限制见[实时设计](design/REALTIME.md)。
- 手动上滚停止跟随，点击“返回最新”恢复。
- 支持当前结果内搜索、逐段复制、全文复制、逐段编辑和定位播放；没有可用录音则不显示播放操作。
- 编辑标记“已编辑”，可恢复原文；后台结果不得覆盖正在编辑或已人工修改的内容。
- 修改英文不自动改中文，标记“英文已修改”；用户点击“重新翻译本段”后才调用本地翻译。
- 可从选中文字进入“添加到课程术语”，影响后续处理，不批量替换已有全文。
- 一个导出入口：TXT、Markdown、SRT；JSON 收进高级选项。支持语言选择，导出当前查看结果及人工修改。
- Markdown 保留段落和时间标记；SRT 按实际时间精度说明，不宣称精确逐句对齐。

## 6. 录音片段与时间轴

### 复习书签（2026-11-05 追加确认，原🎯功能）

- 主窗口和悬浮字幕的每个显示段落右侧使用书签按钮：未标记默认完全隐藏，鼠标进入对应段落或键盘聚焦时显现空心书签，已标记始终为蓝色实心；再次点击取消，保留可恢复记录。
- 字幕工具栏的“标记当前”对应最新显示段落，与其行内书签及复习列表共享保存状态。还没有字幕或仅录音时记录当前采集时间点，字幕到来后关联；不暂停录音、识别或翻译。
- 课后打开标记，显示最新已保存的当前句与紧邻上一句。原音与句界可映射时自动回听这两句，到当前句末停止；缺少句界时可手动从标记前最多 5 秒回听。点一句查课程资料，可为本讲选择课件并按需选词，显示带文件、页码及原文的候选，不自动修改字幕。
- 位置绑定采集会话及时间，字幕晚到、上下文回改、暂停继续、重排录音和移动整个 Lecture 不应让标记串到其他内容。
- 标记只保存身份、时间和复习状态，遵守英文／中文／录音保存开关；仅字幕可复习已保存文字，仅录音可回听，后续生成课后文字后可定位该区间。
- 支持待复习／已复习、确认移除及恢复；原音和字幕不随标记移除。正常退出等待标记保存，失败明确提示并可重试。
- 无原音或旧录音缺少暂停映射时说明限制，不猜测定位；时间点不是逐词对齐承诺。流式初译和必做上下文回改继续保留。

### 录音管理

- 一次开始到结束，对用户显示为一段录音；暂停／继续产生的内部块隐藏，由软件管理。
- 结束后继续录制追加一段；导入的每个文件分别为一段。
- 列表显示名称、时长、录制日期，支持播放、重命名、拖动排序、导入、确认删除。
- 首次批量导入自然文件名排序，后续新增追加末尾，不重排已有列表。
- 整堂转写按列表顺序建立逻辑时间轴，不包含课间暂停，保留源片段和源时间映射。
- 单段菜单提供“仅转写此段”，主流程默认处理全部录音。
- 新增、删除、排序后保留原结果，提示“录音已变化，可重新生成课后转写”；重新处理产生新结果。
- 已运行任务保持启动时的录音顺序；影响其素材的删除须先停止任务。
- 不提供录音裁剪、合并文件、跨 Lecture 移动或复制入口；排序不改写音频。

## 7. 悬浮字幕与退出

- 启动实时字幕默认自动显示悬浮窗，可关闭自动显示；仅录音不显示。
- 与主窗口共享同一 Lecture 和字幕状态，不生成第二套字幕或采集任务。
- 默认中文在上、英文在下且稍小；可选仅中文或双语，独立于主窗口显示设置。
- 鼠标移入显示暂停／继续、返回主窗口、字号与显示设置、隐藏；结束 Lecture 留在主窗口。
- 持续显示“录音中／不保存音频”，暂停时明确显示“已暂停”。
- 可置顶、拖动、缩放，记住位置、字号、透明度；上滚后停止跟随，提供“返回最新”。
- 不放课程资料、模型选择、历史结果或 Lecture 切换。
- 关闭悬浮窗只隐藏；关闭主窗口不停止采集或任务，通过菜单栏找回。首次在采集中关闭主窗口提示一次仍在运行。
- 完全退出时，若正在采集，询问“结束当前采集并退出？”，确认后等待录音封存登记、字幕收尾和本应用后台进程结束；暂停中的录音也要封存。只有离线任务则保存进度后退出，不额外确认。
- 正常退出不能以固定超时丢弃字幕待办。失败不能当作保存成功；可取消退出，取消后不自动开麦。异常强杀的恢复能力另列状态，不由正常退出保护推定。

## 8. 后台任务与模型

- 主窗口统一任务入口，展示所属课程、Lecture、步骤与进度；无法可靠计量时不显示伪百分比。
- 下载支持暂停、继续、失败重试；课后转写支持暂停、继续、取消、失败重试；资料整理自动管理，失败可重试。
- 取消终止本次处理，保留原录音、旧结果及已完成部分；部分结果明确“未完成”，不能当作整堂完成。以后重做创建新任务。
- 优先级：录音写入 → 实时识别翻译 → 用户课后转写 → 资料整理与术语译法补全。
- 开始实时字幕后，冲突的后台推理任务在安全位置让路，显示等待原因；结束后自动恢复。仅录音不要求后台识别停止。
- 用户手动暂停保持暂停；重启自动恢复因退出或中断而停止的本地任务，不恢复手动暂停、取消的任务，不自动开启麦克风。
- 持久化检查点；暂停、让路、取消、失败、恢复在内部明确区分，恢复不重复提交结果。
- 原生采集、推理队列和上下文保持有界，异常不允许无限积压或阻塞录音。
- 主区域移除“大模型”等切换器；设置提供标准识别与高精度识别（记住明确选择，未保存偏好时默认高精度），不承诺未经验证的质量优势。
- 中文翻译模型自动管理，不提供多模型选择；采集中不切识别模型，先暂停再切换，已有离线任务沿用其模型快照。
- 首次下载展示大致体积和用途，提供“下载并准备／稍后”；断点续传、复用缓存，日常更新不无故重复下载。

## 9. 课程整理、删除与存储

- 课程按创建顺序，支持拖动排序；Lecture 按创建时间最新在上，日期独立显示。
- 课程右键：重命名、管理资料、Finder 显示、删除。
- Lecture 右键：重命名、移动到其他课程、Finder 显示、删除；不提供复制。
- 移动 Lecture 带走录音和转写，源课程资料不跟随；后续处理使用目标课程术语，原结果不改写。
- 正在采集时先结束才能移动或删除；后台任务受影响时列明任务，提供“取消任务并继续／返回”，不静默取消。重命名不受此限制。
- 删除统一确认并进入应用废纸篓：课程包含全部所属内容，Lecture 包含其录音和转写；单独删除录音保留文字，缺失音频的段落不可播放。
- 废纸篓支持恢复和清空；清空再次确认并说明不可恢复，普通删除不永久擦除。
- 导入使用受管副本，不修改或删除用户源文件。
- 只使用一个本地资料库，保留真实文件夹和 SQLite；移除多资料库切换，不做云同步。
- 提供打开资料库与备份说明：暂停处理并完全退出后备份整个资料库；不把 Finder 手工改名视为自动同步操作。

## 10. 首次使用、默认值与设置

- 不做强制多页引导。空白主页提供简短说明与“创建课程”；课程创建后可导入资料、已有录音或开始新 Lecture。
- 模型提示卡不遮挡管理功能；选择稍后仍可管理资料和仅录音，需要字幕/转写再提示准备模型。
- 第一次主动采集才请求麦克风权限；拒绝后提供系统设置指引，不阻塞导入录音与离线转写。
- 首次默认录音与双语字幕，保存音频、英文和中文；后续记住选择，明确展示是否保存音频。
- 英语课堂默认固定英语；开放所有语言的自动检测仅为主动选择的实验选项，不称为“自动识别中英”。旧自动偏好一次性迁移为英语；既有会话／结果不改写，配置用于新会话和新课后任务。
- 主窗口英文上中文下，悬浮窗中文上英文下，实时字幕默认自动显示悬浮窗。

| 设置类别 | 内容 |
|---|---|
| 录音与字幕 | 麦克风、默认记录方式、英文保存、中文翻译 |
| 悬浮字幕 | 自动显示、语言、字号、透明度、恢复默认位置 |
| 本地模型 | 当前模型、下载状态、标准／高精度识别 |
| 存储与关于 | 打开资料库、空间占用、备份说明、版本号、复制诊断信息 |

- 语言显示、字号、透明度可随时改；麦克风、记录方式、识别模型先暂停再改。
- 错误信息说明原因、重试或解决路径；不暴露不必要的内部推理参数。
- 诊断信息只含版本、系统、任务状态及过滤后的错误，不包含音频、资料文字、转写、密钥、完整个人路径；用户自行复制发送，不自动上传。

当前已确认视觉为琪露诺冰蓝与录音岛，替代早期暖白绿；详见 [视觉规则与资源](design/VISUAL.md)。实现和未覆盖视觉状态仍见 STATUS。

## 11. 语音增强范围与批准边界

- 口音原音复核、按课程追踪老师、人声分离分别可开关，便于 debug。本轮只批准口音增强；另两项不制作占位开关。
- 已批准保留低延迟首稿，再按原音及相邻语音进行口音复核；保留固定英语、连续字幕和必做中文回改。口音开关独立持久化、实验默认关闭；暂停后切换，继续采集生效。参数可依据测试细化，不将初始建议当已验证规则。
- 复核不可仅凭通顺、术语命中或同模型一致而改写；数字、单位、否定和大范围改写保守拒绝。证据不足保留字幕及候选审计，接受后中文需匹配新英文版本。录音模式可从已保存原音补做；仅字幕不额外持久化音频，不能恢复的边界明确记录。
- 老师追踪希望自动、无需强制声纹注册；不同课程可有不同老师和教室。原录音保留，课堂优先改善字幕，下课后可选生成老师音轨；这些是目标，不是效果保证。
- 资料增强重设计留待后续版本；已知缺口不因此删除。具体未完成项与当前暂停点见 [STATUS](STATUS.md)。

## 12. 验收与不变约束

- 课堂数据只在本地；不新增账号、云总结或自动上传。源录音、人工修改、历史版本不得被后台处理破坏。
- 状态机、存储、恢复与时间轴需要行为验证；构建、CI、短回放通过不等于真实课堂质量、延迟、续航、硬件故障或三小时验收通过。
- 阶段交付曾按用户安排暂缓质量／长时评估；后续明确授权的离线研究已执行，范围见研究报告。未测项目继续列为未验收，不把“暂缓”解释为永远不测试。
- 原 PRD 中已取消的 LF-10 总结／Prompt／云 API，以及 Lecture 专属资料和跨 Lecture 单独录音移动／复制，不重新纳入产品。其余原始需求没有证据被替代的仍保留，编号对照见 STATUS。
