# LectureFlow 0.6.2 · 字幕阅读阶段体验版

面向 Apple Silicon Mac，要求 macOS 26+，建议至少 16 GB 内存。本版集中交付可上手的课堂流程与字幕阅读体验。

## 本次改进

- 主窗口实时记录新增“展开字幕 / 恢复布局”：压缩顶部工具与录音面板，保留计时、采集控制、搜索、字号、复制、导出和返回最新。
- 整理录音波形与控制布局，改善窄窗口和课程侧栏的空间分配。
- 调整悬浮字幕标题栏、透明度、主窗口显示切换与侧栏选中状态。
- 保留课程共享资料、录音与双语字幕、课后转写、历史版本、人工编辑与任务恢复。

## 下载与使用

下载 `LectureFlow-0.6.2-macOS-arm64.zip`，解压后将应用拖入“应用程序”；`SHA256SUMS` 用于校验下载完整性。安装包内含独立 Python 环境，无需另装 Python 或 Xcode；默认不含模型，首次下载需要联网，模型准备完成后课堂处理在本机运行。

更新前结束采集并完全退出旧版本。请保留原有资料库；本次界面更新无需重新导入录音和课件。

应用采用本地签名，尚未 Apple 公证。若系统阻止打开，请核对下载来源并按系统提示处理。

## 验证边界

- 字幕展开与恢复已在已有字幕的 Lecture 上实际点击验证；构建和原生测试通过。发布工作流另执行代码检查、Python／原生测试、独立打包、签名与独立后端启动检查。
- 识别准确率、翻译质量、延迟、续航与三小时稳定性仍暂缓，未标记通过；部分采集中状态、设备切换、睡眠和多尺寸视觉仍依赖实际使用反馈。
- 当前识别与翻译流程以英语课堂到简体中文为主；模型的多语种能力不代表产品已完成多语种适配。
- 当前不含专用语音增强或口音适配；更大识别模型不承诺未经实测的改善。离线字幕仍为约 30 秒处理区间，未逐句精确对齐。
