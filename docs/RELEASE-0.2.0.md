# LectureFlow 0.2.0 · 课堂体验版

下载 `LectureFlow-0.2.0-macOS-arm64.zip`，解压后把应用拖入“应用程序”即可使用。内含运行环境，无需 Python、Xcode 或源码目录。首次打开自动后台下载约 1.86 GB 默认本地模型，支持暂停和继续；更新应用不会重复下载已安装模型。

需要 Apple Silicon Mac、macOS 26+，建议 16 GB 内存。

包含课堂录音与独立开关、流式双语字幕和悬浮窗、历史录音批量导入与后台处理、PDF/PPTX/PPT 课件及本地 PDF OCR、可确认术语、文件管理与可恢复废纸篓、转写导出、总结 Prompt 和可选服务总结。琪露诺 fumo 主题 Logo 与发布页同步更新。

按使用指南设置后，可直接导入录音或开启采集。原始录音不会修改；只有明确确认总结发送时才调用配置的服务。

当前为体验版，识别质量、翻译效果、延迟、续航及长时稳定性等待实际使用反馈。离线字幕为约 30 秒区间；实时修订按语音片段处理。应用为本地签名，未经过 Apple 公证；安装说明见仓库使用指南。

源码和发布包不包含真实课堂录音、课件、转写、API 密钥或私有测试资料。
