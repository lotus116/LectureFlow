# LectureFlow 使用指南

版本、下载和已知问题统一见[当前状态](STATUS.md)；想了解设计见[产品需求](PRODUCT.md)。下列说明区分已可用功能与尚未补齐的入口。

## 安装

**Windows 11 x64**　从[0.6.5 发布页](https://github.com/lotus116/LectureFlow/releases/tag/v0.6.5)下载 Windows ZIP，完整解压后双击 `LectureFlow/LectureFlow.exe`。默认模型随目录分发，升级前结束采集并退出，解压到新目录。个人资料位于 `%LOCALAPPDATA%/LectureFlow/Library`。系统入口、CPU/Vulkan 和本地 OCR 见[Windows 使用与验证记录](research/WINDOWS-TRIAL.md)。

**macOS**

从 [GitHub 发布页](https://github.com/lotus116/LectureFlow/releases/latest)下载 Apple Silicon ZIP，解压后将 LectureFlow.app 放入“应用程序”。要求 macOS 26+，建议至少 16 GB 内存；包含独立 Python，无需另装 Python 或 Xcode。更新前结束采集、完全退出旧版，保留资料库和模型。

首次准备模型需要联网，模型下载可暂停／继续，之后课堂处理在本机完成。应用本地签名、尚未 Apple 公证；系统阻止打开时核对来源并按系统隐私与安全提示处理。发布页提供 SHA256SUMS 用于校验。

## 最短试用

1. 新建课程，进入课程主页。可先导入课程资料，也可直接开始。
2. 选择“开始新 Lecture”（沿用记录方式）、“新建 Lecture”，或“导入已有录音”。取消导入不留下空记录。
3. 选择录音与双语字幕、仅录音、仅字幕。点击开始，暂停后继续同一段；“结束 Lecture”封存，之后“继续录制”追加新段。
4. 在“转写”页查看实时记录；要处理已保存原音，主动生成课后转写。不会结束后自动整堂重跑。
5. 课后结果可编辑段落、恢复原文，英文修改后可显式重译该段；实时记录尚无对应编辑入口。0.6.4 起支持下述书签复习定位。实时导出目前为 Markdown／JSON，课后支持 TXT／Markdown／SRT／JSON；统一按当前语言导出仍有缺口。

## 用书签标记听不懂的位置

上课时点“转写 → 实时记录”工具栏的 **标记当前**，或悬浮字幕顶部的 **书签按钮**，标记最新显示的一段字幕。想补标前文，把鼠标移入对应段落再点右侧书签。**未标记默认不显示图标，鼠标进入或键盘聚焦时显现；已标记始终显示蓝色实心书签**。行内书签、标记当前、浮窗和复习列表共享状态，保存成功后变色；再次点击取消，可恢复。字幕尚未出来或仅录音时仍可先记录当前采集时间点，之后关联对应内容。标记保存在本地，重启仍在。

下课后进入同一 Lecture，点采集区的 **复习标记**，选择时间点即可看到标记时的当前句和紧邻的上一句。保存了原音且能定位句界时，会从上一句开头自动播放到当前句末尾；只有当前句就只播这一句。只有录音或句界无法映射时，可手动从标记前最多 5 秒回听。可标为已复习；误取消／移除后勾选列表上方 **已移除**，选择标记恢复。

0.6.5 支持课后查拼写。回听后点其中一句，在 **本节课件** 选这堂课的 PPT 或 PDF（也可查全部课程资料）。展开结果可看文件名、页码和页内文字；需要时用 **选词缩小范围** 指定原句中连续的一至四个词。课件写法仅供对照，标记和查询不改字幕。

时间使用该次采集的字幕时钟，包含暂停间隔，可能与录音岛的有效采集时长不同；回听会换算掉暂停。旧录音没有完整暂停映射时仅显示文字及定位限制，可从录音页播放。仅字幕模式不补存原音，关闭英文保存也不会因为打标记而保存隐藏英文。流式初译和上下文回改保持运行，复习时显示最新已保存的版本。

## 展开字幕阅读

“转写 → 实时记录”中的“展开字幕”压缩顶部标题和录音面板，保留计时、采集控制、搜索、字号、复制、导出和返回最新。“恢复布局”或切换 Lecture 恢复常规布局。只影响主窗口布局，悬浮字幕单独开关。

## 记录方式

- 首次默认录音与双语字幕；仅字幕明确不保存音频。细分英文／中文保存项在设置中，翻译开启仍需内部识别，英文可不显示／不保存。
- 切换记录方式、麦克风或识别模型前先暂停。未保存模型偏好时默认高精度，已选择标准档的偏好会保留。
- 模型未就绪且允许录音时先保存音频、提示字幕准备中；准备前的音频不暗示已补字幕，可课后转写。仅字幕模式等待或改为仅录音，不偷偷保存音频。
- 暂停不清零计时，也不新增用户录音行；底层暂停块隐藏。录音岛显示波形、计时与控制，源文件名和历史不因友好显示名变化。

## 课程资料与术语

PDF/PPT 归属课程，供该课程所有 Lecture 使用。自动整理拼写提示；辅助术语可修改、停用、手动添加，人工记录优先。自动中文为“译名建议”，只有可靠课件对照或人工译名按当前句子参与翻译；不确定可留空，不需要逐词审核。

术语修复会基于缓存页文字重建旧派生词表，保留人工修改与停用；历史转写不自动重写，可主动生成新版本。资料不是越多越好，也不能保证专业词一定识别正确。

0.6.5 将批量导入失败隔离到单份文件：其余文件继续导入，结果区区分成功、重复跳过和失败；展开查看原因，点击“重试未完成项”只处理失败或未处理文件，不重复导入成功项。结果保留在当前资料窗口，关闭后可重新选择文件，已有内容会自动去重。

仍有限制：重新处理／新版替换入口不完整；已运行字幕会话不会立即刷新资料快照。详见 STATUS 的 A04/A05。

## 悬浮字幕与退出

开始实时字幕可自动显示悬浮窗；窗内有暂停／继续、返回主窗口、字号／显示和隐藏。结束 Lecture 在主窗口操作。关闭悬浮窗只隐藏，关闭主窗口不停止采集；浮窗历史上滚冻结仍不完整，长段回看优先使用主窗口。

完全退出时若正在采集，会询问是否结束；确认后等待录音封存登记、字幕补做与后台收尾，暂停录音也会封存。可以取消退出，取消后不自动开麦。失败会列出问题，默认留在应用；明确选择带警告退出不代表全部保存成功。

系统注销／重启若被保存流程拦下，等保存退出后再次操作。强制退出、断电、模型崩溃不能保证内存待办补齐。

## 后台、删除与备份

课后任务可暂停、继续、取消和失败重试；手动暂停不会被自动拉起，取消保留已有结果且以后重做创建新任务。删除进废纸篓，可恢复；清空再次确认。可移动整个 Lecture，不提供单独录音跨 Lecture 移动／复制入口。活跃重命名及任务冲突操作仍有 A08 限制。

独立包默认资料库位于用户 Application Support 下的 LectureFlow/Library，但已保存路径可能沿用；以设置中“打开资料库”实际打开的位置为准。备份前暂停处理并完全退出，复制整个资料库。历史迁移的原副本／备份不会自动同步新课堂，同一磁盘副本不替代异盘备份。不要在 Finder 手工改名后假定应用自动同步。

## 设置与语言

设置分为录音与字幕、悬浮字幕、本地模型、存储与关于；单一本机资料库，不通过界面切换多个库。诊断可手动复制，不自动上传课堂内容。

新会话／课后任务默认英语；旧版自动偏好迁移为英语。开放所有语言检测是实验选项，重口音仍可能误判。新设置用于新会话／新任务，旧记录不改写；已有自动会话可结束后继续录制或新建 Lecture。单段转写入口未正确继承实验语言偏好，仍采用英语默认（A07）。

## 限制与反馈

后文会用于回改前两段中文，积压只延后已登记的必做回改，正常停止前补做；不承诺一秒出字。字幕无进展会有限恢复，恢复／过载可能有缺口；达到上限可暂停再继续，保存了原音时可课后生成新转写。仅字幕不能补齐未保存音频。

课后字幕时间戳约为 30 秒处理区间，并非逐词精确。准确率、翻译质量、真实语义延迟、续航和长时／硬件异常仍未完整验收。口音原音复核、老师追踪、人声分离及三个新开关尚未上线。

本人上课试用同样属于反馈流程：记录版本、操作、问题时间、预期与实际结果；无需默认上传录音、课件或逐字转写。本地测试包文件名带日期／提交，正式包看发布页版本；先完整退出旧应用，再替换安装。

## 口音增强测试构建

设置 → 记录方式细节 → **口音增强（实验）**，默认关闭；暂停后切换，再继续采集。仅固定英语生效，会增加本地原音复核开销；原字幕先显示，证据不足不改写。它不包含老师追踪或人声分离。仅字幕不保存音频，退出后不能补回其内存原音。当前验证与已知限制见 [口音测试记录](research/ACCENT_IMPLEMENTATION-2026-11-05.md)。
