# LectureFlow 使用指南

## 安装

需要 Apple Silicon Mac（M 系列）、macOS 26 或更高版本，建议 16 GB 内存。当前固定的本地推理依赖要求 macOS 26；不支持 Intel Mac。

从 [发布页](https://github.com/lotus116/LectureFlow/releases/tag/v0.2.0) 下载 `LectureFlow-0.2.0-macOS-arm64.zip`，解压，将 `LectureFlow.app` 拖入“应用程序”后打开。包含独立 Python 运行环境，不需要源码目录、终端或 Xcode。首次打开会自动后台下载约 1.86 GB 的轻快识别与中文翻译模型，可先创建课程、导入资料或保存录音；模型就绪后可离线识别。下载支持暂停和继续，应用更新复用缓存，高精度模型按需下载。

当前构建使用本地签名，尚未经过 Apple 公证。若系统阻止打开，可在“系统设置 → 隐私与安全性”中核对应用来源后选择“仍要打开”；无需关闭系统安全保护。

## 第一次使用

1. 新建课程，再在该课程中“新建课堂”。
2. 历史录音：导入 M4A、MP3、WAV 或 FLAC，也可从 Finder 拖入；初始按自然文件名排序，随后拖动片段到正确顺序。
3. 点击“转写整堂课”，或处理某一段。可暂停、继续、取消，失败后重试；已处理内容与旧版本保留。
4. 查看双语转写，可搜索、复制或导出 Markdown、TXT、SRT、JSON。

## 实时课堂

“全部开启”同时启用保存录音、英文转写和中文翻译；三个开关也可分别控制。首次开启会请求麦克风权限。

- 暂停后继续仍属于同一课堂，录音保存为新的逻辑片段。
- 关闭保存录音时，只处理字幕，不保存原始声音。
- 仅开启中文翻译时，内部识别仍运行，但英文不输出或保存。
- “取消本段录音”需要确认；录音封存后进入应用废纸篓，字幕按原开关继续。
- 右上角“悬浮字幕”可置顶、拖动、缩放，调整字号和背景透明度，按需显示英文。
- 手动滚动字幕时停止跟随；“返回最新”恢复跟随。主窗口和悬浮窗共用同一课堂。
- 更换麦克风须先暂停。切换识别模型时，等待当前语音片段结束后加载，录音写入独立继续。

关闭窗口不取消后台任务。完全退出应用会结束本次麦克风采集并封存录音；重新打开后可恢复未完成的离线任务。意外退出后使用“恢复录音”重新登记已保留的录音块。

## 课件与术语

“课件与术语”导入本课堂 PDF、PPTX、PPT。课程名称的右键菜单可添加共享课件，供课程下所有课堂使用。

扫描 PDF 自动使用 macOS 本地 OCR；图文混合 PDF 可选择“强制 OCR”。PPTX 按幻灯片顺序提取文字；旧版 PPT 提取文本记录。图片型 PPT 建议另存为 PDF 后导入。加密文件请先解锁；单文件最多 250 MB、1000 页。

自动提取的是术语候选。核对后勾选，可编辑中英对照或手工添加。确认术语用于后续识别与翻译；实时字幕重新开启后应用更新。课件参考仅用于消歧，识别原文保留。更换资料后旧转写和总结标记为可能过期。

## 文件管理

课程和课堂支持右键重命名、移动与移入废纸篓。课程可拖动排序；课堂可拖到另一课程。录音可拖到另一课堂；按住 Option 拖动可复制，也可使用片段菜单。

删除只影响受管副本，需要确认，可从应用左下角废纸篓恢复。源文件不会更改。整理文件前暂停采集；若后台任务仍在占用资料，会提示先暂停处理。

资料保存在真实文件夹中，索引为 `Library.sqlite3`。请通过应用整理资料；Finder 用于查看、备份和导出，不自动同步手工改名。设置中可选择其他资料库，完全退出并重开后生效。复制备份前暂停处理并完全退出应用，复制整个资料库文件夹。

## 课堂笔记

无需 API：复制总结 Prompt，或导出转写和相关课件文字，在自己选择的工具中使用。

应用内总结：在设置填写兼容服务的 HTTPS 地址、模型名称和 API 密钥，保存设置。密钥按服务地址保存在 macOS Keychain，不写入数据库或日志。选择转写版本或实时字幕，决定是否包含关联课件，预览后确认发送。只发送预览的文字，不上传录音或课件原文件。

长材料分块整理后整合，已完成分块持久化保存。连接中断后可预览原任务材料并继续；不会自动发起付费请求。完成后可查看、复制、打开 Markdown 与 JSON 文件。

## 模型与限制

默认使用 Qwen3-ASR-0.6B 和 Hy-MT2-1.8B 的固定本地量化版本；设置中可另行下载高精度识别模型。模型仍为候选，未冻结最终选型。

这是可上手的体验版。按用户安排，人工准确率、翻译质量、实时延迟、续航及三小时连续采集评估暂缓，不代表相关指标已通过。

- 离线 SRT 的时间戳为约 30 秒处理区间，尚未逐词对齐。
- 实时修订以有界语音片段为单位，保留最近三段，尚非精确语义句界。
- 繁复版面、图片型 PPT 和特殊旧版 PPT 可能需要另存为 PDF；OCR 和术语候选需要核对。
- 本地签名尚未公证。云端总结协议使用模拟服务检查，未发起真实计费调用。

提交反馈时提供操作步骤、预期与实际结果即可，请勿默认上传原录音、课件、密钥或含隐私的日志。
