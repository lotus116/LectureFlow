# LectureFlow 使用指南

## 安装

需要 Apple Silicon Mac（M 系列）、macOS 26 或更高版本，建议 16 GB 内存。

从 [发布页](https://github.com/lotus116/LectureFlow/releases/latest) 下载 macOS 压缩包（或使用本机预览包），解压后将 `LectureFlow.app` 拖入“应用程序”。自带运行环境，无需 Python 或 Xcode。首次打开会后台下载约 1.86 GB 默认模型，可暂停继续；之后可离线使用。

当前构建使用本地签名，尚未公证。若系统阻止打开，在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 最短试用

1. 新建课程；点击课程进入主页。
2. **开始新 Lecture**（沿用上次记录方式），或 **新建 Lecture** / **导入已有录音**（取消文件选择不会留下空记录）。
3. 可选：在「课程资料」批量导入 PDF/PPT；术语自动启用，供本课程所有 Lecture 使用。
4. 主按钮：开始 → 暂停 → 继续；**结束 Lecture** 封存本段。结束后可 **继续录制** 追加下一段。
5. 「转写」页在实时记录与课后转写间切换；需要时点 **生成课后转写**。可编辑段落、恢复原文、对英文已修改段 **重新翻译本段**。
6. 导出 TXT / Markdown / SRT（JSON 在导出目录中）；无云端笔记或 API。

## 展开字幕阅读（0.6.2）

进入 Lecture 的「转写 → 实时记录」，点击「展开字幕」；顶部大标题、完整录音面板与页面切换栏会收起，为字幕留出更多空间。计时、暂停／继续等采集控制，以及搜索、字号、复制、导出与返回最新仍可使用。

点击「恢复布局」返回常规界面；切换 Lecture 后也会恢复常规布局。展开阅读仅调整主窗口布局；悬浮字幕可按需单独打开。

## 记录方式

主分支开发版采用冰蓝主题。录制／暂停时显示波形、计时及独立结束按钮；结束后切为保存状态和继续入口。自动录制条目显示“录音 01”等名称与本地时间，完整原名保留在悬停提示中；导入文件与恢复警告保留原有名称。此项不改动源文件或历史转写。

- **录音与双语字幕**（默认）、**仅录音**、**仅字幕（不保存音频）**。细分保存项在设置中。
- 切换记录方式或麦克风须先暂停。翻译开启时内部识别仍运行；英文可不显示/不保存。
- 模型未就绪且允许保存音频时立即录音，显示字幕准备中；仅字幕则等待或改选仅录音。
- 暂停不清零计时，继续属于同一段用户录音；内部暂停块不单独列出。

## 课程资料与术语

资料一律归属课程。导入后自动整理英文拼写提示；「查看辅助术语」可修改、停用或手动添加，人工修改优先。自动生成的中文标为“译名建议”，不直接约束翻译；课件明确中英对照和人工校正才按当前语句参与翻译，冲突时不采用。无需逐词审核，中文可以留空。词表只传相关小部分，不整表灌入，不擅自改写历史转写。

升级此修复后，打开课程资料会自动用缓存文字重建派生词表，保留人工修改和停用记录，不用重新导入。旧的自动错误译名会清除；已完成转写保留，如需纠正请主动生成新版本。

## 悬浮字幕与退出

开始实时字幕默认可自动显示悬浮窗。窗内：暂停/继续、返回主窗口、字号与显示、隐藏。结束 Lecture 请在主窗口操作。关闭悬浮窗只隐藏；关闭主窗口不停止采集。完全退出时若正在采集，会询问是否结束并封存。

## 后台与删除

后台任务可暂停、继续、取消、失败重试；手动暂停不会被自动拉起。取消保留已有结果。删除进废纸篓，可恢复；清空需再次确认。不提供跨 Lecture 移动/复制录音入口；可移动整个 Lecture 到其他课程。源文件不被修改。

## 设置

录音与字幕、悬浮字幕、本地模型（标准/高精度）、存储与关于（打开资料库、备份说明、复制脱敏诊断）。单一本机资料库；界面不再切换多库（开发测试仍可用环境变量注入隔离路径）。

## 限制

模型仍为候选。准确率、延迟、续航与三小时稳定性按安排暂缓评估，不表示已通过。时间戳约为 30 秒处理区间。本地签名未公证。
