# 琪露诺冰蓝与录音岛 · 2026-10-31

范围：LF-UI，关联 SD-01 / SD-04 / SD-05 / SD-06。用户确认冰蓝方向，同时希望保留参考录音机的横向波形、大计时、暂停与结束按钮。本轮在 SwiftUI 中实现；属于主分支开发更新，尚未重新发布安装包。

## 视觉与操作

- 浅色画布、侧栏、面板分别为冰白、浅冰蓝和白色；深色单独采用蓝灰底色。按钮填色与文字强调色分开，深色文字和图标使用更浅的冰蓝。保存成功保留绿色，采集和结束按钮保留红橙语义。
- 采集中／暂停时保留圆角录音岛：短麦克风电平波形、大计时、暂停／继续、独立结束按钮。波形仅表示实时输入电平，暂停冻结；显示缓冲有上限，不代替录音文件的完整波形。
- 结束后显示紧凑保存状态、最近采集时长和继续入口，不再显示大型波形或红色开始圆点。仅字幕模式的继续入口显示“继续字幕”；正在写入时不显示保存完成标记。
- 录音列表统一为细线分隔的连续列表，保留播放、排序、单段转写、导出与废纸篓操作；顶部“导入”降低视觉权重。
- 自动录制名称显示为“录音 01”等顺序名称，副标题显示本地日期／时间和时长。原文件名保留在悬停提示中；导入文件名、格式异常和恢复警告保持原有标识。此项仅格式化显示，不重命名文件，不写回数据库。
- 顶部补充课程名，明确总录音时长；课程可原生折叠，折叠不切换当前 Lecture。选中项使用浅蓝底与深蓝／浅蓝文字。
