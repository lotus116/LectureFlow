# 0.3 使用反馈改进

本轮以用户实际使用反馈为准，先修数据隔离，再完善悬浮工作方式和课件增强，最后统一界面与打包。

| 反馈 | 实施与检查 |
|---|---|
| 同名课程疑似转写冲突 | 切换立即清空，异步读取绑定课堂/版本，忽略过期响应；同名新旧课程的存储、恢复、清空隔离测试 |
| 废纸篓不能清空 | 显示来源与删除时间；清空前列明范围并确认；只删除确认快照中的废纸篓项目，保留正常课程；中断可恢复清理 |
| 悬浮字幕依赖主窗口 | 实时开启后可自动显示，独立控制暂停/恢复、语言与样式，支持切到其他应用和主窗口隐藏后的继续显示 |
| 课件增强过弱 | 内容大纲与概念索引、带出处的术语候选、自动拼写提示、识别过程动态选取相关词；批量采用/忽略/中文补全与持久化进度 |
| 界面松散、复杂 | 紧凑侧栏和固定工具栏，减少常驻状态卡片；录音、转写、课件和笔记按当前任务呈现，突出悬浮入口 |

本轮验证功能、存储和恢复，不把模型质量、延迟或长时评估写为已通过。不对真实资料执行清空测试，也不发起计费 API 请求。

已完成代码及本机 Release 打包，83 项 Python 与 10 项原生测试通过。数据库升级到索引版本 4，升级前保存旧数据库备份。下一步为 GitHub 检查、发布包与用户实际反馈；质量与长时评估继续暂缓。
