# LectureFlow 0.6.3 · 英语字幕与退出保存修复

本版汇总已完成的课堂使用修复：英语课堂默认固定英语识别，恢复积压后的上下文翻译回改，退出应用时等待录音保存和字幕收尾。

## 修复内容

- **英语课堂语言误判：** 新会话和新课后任务默认固定英语；旧自动偏好一次性迁移。自动检测保留为实验选项，不将模型多语种能力等同于产品适配。
- **上下文翻译回改：** 前两段的必做回改在短暂积压后补做，移出窗口或正常停止前完成再锁定，保留原始识别和修订记录。
- **退出保存：** 退出时等待录音封存、登记、字幕收尾和本应用后台进程结束；暂停中的录音也会封存。保存失败不会自动判为成功，支持取消退出。
- **字幕与模型偏好：** 保留有限字幕恢复、连贯阅读分组与已选择的模型偏好；未保存偏好时使用高精度档。

本次归档[语音增强研究报告](https://github.com/lotus116/LectureFlow/blob/main/docs/SPEECH_RESEARCH-2026-11-05.md)，口音原音复核、老师追踪和目标人声分离仍待讨论，未集成到本版。

## 安装与更新

适用于 Apple Silicon、macOS 26+，建议至少 16 GB 内存。下载 `LectureFlow-0.6.3-macOS-arm64.zip`，解压后将 `LectureFlow.app` 拖入“应用程序”。更新前结束采集并完全退出旧版，保留已有资料库和模型。

安装包包含独立 Python 运行环境，无需另装 Python 或 Xcode；不含模型权重、课堂录音或课件。首次准备模型需联网，课堂处理在本机完成。`SHA256SUMS` 用于核对下载完整性。

应用采用本地签名，尚未 Apple 公证；若系统阻止打开，请核对来源并按系统提示处理。

## 验证与边界

- 发布准备已通过 129 项 Python 测试、35 项原生测试和 ruff 检查；另实际验证 AppKit 退出中的等待、重复请求、失败保持运行及取消退出四种隔离场景。
- 发布工作流会再次执行检查、独立打包、签名验证及包内后端启动检查；最终工作流结果见本次 Release 对应 Actions。
- 本地研究包含真实录音与公共语音的离线对照，但不代表真实课堂准确率、翻译质量、延迟、续航或三小时稳定性通过。
- 正常退出的保存等待不能保证异常强杀或硬件故障后的完整恢复；异常强杀待办恢复仍未实现。系统注销／重启若被保存保护拦下，需要在保存退出完成后再次操作。
- 专业词、重口音、混响与重叠讲话仍可能识别错误；默认固定英语也不等于完成中英自动切换。离线字幕时间戳仍约为 30 秒处理区间。
