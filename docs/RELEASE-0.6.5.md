# LectureFlow 0.6.5 · macOS 与 Windows

这次发布把 Windows x64 课堂版与 Mac 上的书签查词、中文回改和数字修复放在同一版本。两端都在本机处理课堂录音和字幕。

## 下载与安装

| 平台 | 选择与使用 |
|---|---|
| Apple Silicon，macOS 26 或以上 | 下载 `LectureFlow-0.6.5-macOS-arm64.zip`，解压后将应用放进“应用程序”。首次使用需准备本地模型；升级时沿用已有模型和资料库。应用使用本地签名，尚未经过 Apple 公证。 |
| Windows 11 x64 | 下载 `LectureFlow-0.6.5-Windows-x64.zip`，完整解压后双击文件夹内的 `LectureFlow.exe`。目录包含默认识别模型、翻译模型和运行环境。英文识别用 CPU；中文翻译可选 Vulkan 或纯 CPU。 |

更新前请结束录音，等保存完成并退出应用。Windows 请解压到新目录，保留原有 LocalAppData 资料库。发布页中的 `SHA256SUMS` 可核对下载文件。

## 本版改进

- **Windows 课堂工作区。** 支持录音与暂停继续、导入音频、主窗与置顶双语字幕、通知区域控制、本地课程资料与 OCR、课后转写、版本编辑和导出。复习时可定位原音、核对课件拼写。
- **慢一拍也能复习。** 上课沿用“标记当前”。课后可回听上一句和当前句，点一句查课件，按需指定本节文件或缩小到连续一至四个词。结果提供文件、页码和页内文字。
- **中文回改与数字。** 保留实时初译和后文回改，对明显混入邻句的回改保留同源译文，并保护若干可明确对应的小数及数量级。Mac 实际课程的 741 条最终字幕回放中，5 条串句、2 条数值错误得到修正，其余 734 条相同。这项结果针对中文翻译，不用于推算跨平台识别准确率。
- **资料导入和当前句等待。** 批量导入时一份失败后继续处理其余文件，可只重试未完成项。当前句初译单独计时，术语检索也收紧了短子串匹配。

Windows 移植阶段在一台 Windows 11 电脑上验证了真实麦克风短录、十分钟公开课回放和课后转写。不同电脑的驱动、远场重口音、三小时负载与续航仍需验证。实验性口音复核目前仅在 Mac 提供，默认关闭。操作及测试条件见[使用指南](https://github.com/lotus116/LectureFlow/blob/v0.6.5/docs/USER_GUIDE.md)与[Windows 验证记录](https://github.com/lotus116/LectureFlow/blob/v0.6.5/docs/research/WINDOWS-TRIAL.md)。
