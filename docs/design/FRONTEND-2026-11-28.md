# macOS 课堂界面改动

## 三组实际改动

1. **开课前的选择更清楚（SD-01/04）。** 课程主页在“开始新 Lecture”旁展示已有记录方式；
   “新建空 Lecture”“导入已有录音”从更多菜单移为次级按钮；资料入口带份数。空课程只保留一个开始主按钮。
   行为仍调用原来的创建、导入和开始方法。
2. **录音状态和操作不靠猜（SD-04/08）。** 常规录音岛为暂停／继续及结束按钮补常显文字；
   完整提示移至独立可换行区域，避免窄窗把字幕中断及补救说明截成省略号。
   阅读展开模式仍使用紧凑控制；录音计时、保存和结束逻辑不变。
3. **双语阅读空间与长句完整性（SD-05/06、A06 展示）。** 主窗复制／导出合并到次级菜单，
   书签和返回最新保留直接入口；搜索无结果有明确空态。中文正文使用独立深浅色阅读颜色，实时与课后共用。
   浮窗去掉中英文固定行数上限，内容可滚动读完；滚轮／阅读键停止跟随，“最新”立即定位末尾。
   字号按钮有独立可访问名称，相关滚动动画遵守减少动态效果。

完整应用复验另外发现：原先的实时／课后跳转监听放在尚未挂载的内容子视图上，且普通标签默认选择可能覆盖
明确的跳转目的。现在由父视图处理明确目标，普通点击标签才应用原有默认选择。只修正界面目的页，不改变结果或推理。

视觉清单 `design-system/lectureflow/MASTER.md` 校对到现有 `LFChrome` 数值；没有重做主题。
新颜色仅用于中文正文。选中／暂停／结束仍使用原来的系统语义及状态文字。
中文正文在浅色面板／画布上的色值对比度为 7.74／7.45，深色为 9.97／11.35。
原 VISUAL 写侧栏 240 点，而当前代码为 220 点（窄窗 168）；本轮没有更改窗口或侧栏默认值。
