# Opus 审美方案的 macOS 前端实现与验收

## 范围与依据

用户授权 Opus 主导审美、Codex 实施与验证；协调会话提供已取得的设计原稿和后续琥珀配色稿。
只在独立 `codex/opus-frontend-polish` 分支实施，基线为
`384d4d1d5de93c9dee0d9babeff28d92a9705fc3`。原工作树、已安装 App、正在使用的实例不变。
版本仍为 0.6.5 基础上的本地开发候选；不推送、安装或发布，不在本实施发外部模型请求。

仅修改 macOS View／表示层、纯 UI 测试、合成预览和设计记录。
Workspace、音频、生命周期、数据、模型、ASR／翻译、后台、Windows／Android 均不改。
保留原音、人工编辑、实时初译与必做回改，复核接受／忽略／撤销和存储含义不变。

## 优先解决的三个课堂问题

1. **状态层级不清。** 模型未就绪、字幕恢复、失败原先缺乏统一层级。新增轻量 `LFStatusBanner`，
   13 点正文、10×8 内边距，长文案可换行、动作可移到下一行，没有固定 36 点高度。
   信息与准备态为安静中性底；恢复／错误增加不同图形、语义色和边缘标记，不只靠颜色。
   消息与动作仍来自原状态；恢复提示的文字分类仅影响表现，不驱动业务。
2. **导航的两个层级像同一组选择。** 录音／转写改为一级页签，实时记录／课后转写作为带“来源”标签的
   低强调下级选项。继续分别使用原 `tab` 与 `transcriptSource`，原路由函数不变。
3. **复核差异难扫读、小窗内容被挤压。** 英文差异保留 +/-，加可读增删色及“删除／新增”辅助功能名称，
   空间不足纵向换行。保留固定底部回听与决定按钮。录音页在 740×520 中空态原先裁切，
   现在可用高度不足 210 点时改紧凑横排、滚动保留入口。

默认琪露诺冰蓝原色不变；唯一备选浅色按 Opus 改为琥珀，详见 [配色规范](THEMES.md)。
旧 `forest` 存储值保留，显示名称为“琥珀”；没有偏好迁移，不改原有深色适配或浮窗策略。

独立预览：`dist/frontend-preview/opus-candidate/LectureFlow Frontend Preview.app`；
同基线旧预览：`dist/frontend-preview/opus-baseline/LectureFlow Frontend Preview.app`。
二者使用独立 bundle ID、UserDefaults、合成资料库；预览强制从浅色起始，没有改产品外观策略。
构建可通过 `--python /path/to/existing/.venv/bin/python` 复用已安装依赖，显式验证 `PYTHONPATH` 指向本候选 `src`。
只在预览副本替换静音采集、禁用下载／模型推理；真实写盘、封存、登记与回听路径仍运行。
没有使用真人录音、课件、标注或密钥。

本候选按要求复用外部绝对解释器，没有复制或链接依赖冒充此项通过。复核／书签后台契约 20 通过。

## 验证限制

- 录制是静音 PCM；英文／中文、恢复／错误、复核候选是合成夹具，不验证真实麦克风、模型质量或课堂延迟。
- 色彩对比度使用实际代码色值计算，未进行校准的屏幕像素测量。
- 浮窗保持同应用 key window，外部投影片应用、全屏 Spaces 的焦点未实测。
- 系统完整键盘访问未开启，Tab 检查不代表全部按钮遍历；VoiceOver、系统提高对比度／减少透明度未做完整流程。
- 减少动态效果由预览注入，未切换用户系统设置；保留原动效，可在预览展开／恢复字幕与侧栏复验。
- 存储／设备选项、真实资料导入、危险确认、长课堂、休眠、硬件异常、续航与其他平台未新增验收。
- 预览依赖本机环境，不是正式可分发包；未推送候选，因此没有候选远端 CI 或正式发布结果。
