# macOS 全前端逐屏核对

最新 Lecture Rail 重排及逐屏验收见 [本轮记录](LECTURE-RAIL-2026-11-28.md)。下方为前轮基线。

后续 Opus 审美实施见 [本轮变更与验收](OPUS-FRONTEND-2026-11-28.md)。本清单覆盖实际可达界面，
下方原有验收记录保留为基线历史；不能替代新候选结果。

首轮用户授权由 Codex 直接主导设计。使用本机 ui-ux-pro-max 的原生 SwiftUI

## 统一规则

- 阅读优先：内容列最多 680 点，英文在上、中文在下；普通正文 14 点，字幕沿用可调 12–28 点，
  中文按既有比例放大；行距随字幕字号增长。系统中英字体、等宽数字计时、SF Symbols。
- 默认琪露诺冰蓝与可选琥珀共用语义角色；红色只承载录制等既有含义，状态同时有文字／图形。
  原浮窗保留深底白字，不增加深色或跟随系统选项。第二套浅色采用用户确认的 Opus 琥珀方案，旧深色适配保留。
- 桌面原生按钮：主操作用 borderedProminent；并列辅助操作用 bordered 或 borderless。
  常规系统控件保持 macOS 尺寸（通常约 22–28 点高，实际随系统布局），不套用移动端 44 点按钮。
  图标操作的显式区域通常 28 点；常规录音运输控件 40／48 点，阅读紧凑态 30 点并保留文字。
- 页面边距宽窗 24、窄窗 14；常用间距 8／12／16。面板只分隔录音控制与正文，不增加装饰卡片。
- 错误和重要状态可换行；有动作的区域不以颜色作为唯一提示；保留原生按下、禁用和焦点反馈。
- 动效仅用于用户展开／收起、侧栏、选择／按下反馈，160 ms；遵守减少动态效果。
  字幕追加、同段中文回填和版本更新立即呈现，不逐次动画，不让录音／英文等待动效。

## 实际可达界面与处理方式

下表是代码与实际入口清单；“保留”有明确理由，不表示每个危险操作都已执行。具体通过／未测见验收记录。

| 界面／状态 | 主操作、辅助／危险操作 | 布局与控件处理 |
|---|---|---|
| 首次空库 | 中央新建课程；侧栏底部设置／废纸篓 | 保留单一主入口、应用图标及原生空态；不增加介绍卡片 |
| 课程主页：空／有讲次 | 上方开始新 Lecture；下方新建空记录／导入；右上课程资料 | 保留已验证直达入口、方式提示和安静列表；跟随两套主题 |
| 课程／Lecture 侧栏 | 点名称导航；上下文菜单重命名／移动／移入废纸篓 | 保留原生折叠、拖放及菜单替代；补语义定位，危险操作仍确认 |
| Lecture 录音页 | 上方采集控制；录音行播放；尾部导出／移除 | 不改采集／文件行为；图标保留名称，计时统一系统等宽数字 |
| 录制前／中／暂停／停止 | 开始／暂停／继续与独立结束；模式／模型辅助入口 | 正常录音岛保留；窄字幕页压缩控制区，文字操作仍常显；按钮完整区域可点击，修复结束按钮空心部分点击落空 |
| 采集方式弹出层 | 方式选择；暂停后可改；取消当前段为危险次级入口 | 保留原生选项、禁用状态和取消确认，不改开关语义 |
| 模型选择弹出层 | 当前模型／切换／下载 | 保留已就绪、未安装及禁用状态；不重新设计模型默认与下载行为 |
| 实时主窗与展开态 | 语言／字号／搜索；标记当前／返回最新；更多菜单 | 保留 680 点阅读宽度；不显示无关的已完成课后任务条；实时页去掉重复的标记当前入口；展开动效仅由用户触发 |
| 实时空态／无匹配／中文排队 | 等待／清除搜索／队列文字 | 不混淆未开启字幕与等待讲话；状态可读，不做状态卡片堆叠 |
| 浮窗与最窄态 | 采集状态／暂停／标记；显示设置／主窗／隐藏 | 保留 0.2–1 透明度偏好及 320 点最小宽；文字／控件有局部深色衬底；长中英可滚动；最小高度随字号确保至少可读一行；无逐修订动画 |
| 浮窗显示弹出层 | 语言、字号、透明度、自动显示 | 保留原生选择器／滑杆，字号 16–56；高对比或减少透明度用不透明底色 |
| 课后结果／历史／搜索 | 结果与版本选择；搜索／语言／字号；导出／段落菜单 | 共用正文语义色和阅读尺度；历史与原稿含义不变 |
| 段落编辑 sheet | 保存／取消；英文、中文输入 | 保留多行原生输入、取消 Esc；不调整人工编辑／重新翻译规则 |
| 书签列表与回听 | 左侧选择，右侧原音／查课件；已复习／移除／恢复 | 保留列表—详情和原音边界；关闭窗口即停回听，防迟到读取再启动 |
| 书签选句／查词／资料出处 | 选句或词、资料选择、展开来源／打开原件 | 保留证据优先和原生菜单；不新增推理或自动采纳 |
| 优先复核列表与比较 | 选择片段；回听；接受／忽略／撤销／返回 | 纵向原稿—候选比较，长文滚动；回听与决定固定在底部，接受为唯一强调操作 |
| 课程资料／批量处理 | 导入；每项重试／打开／移除；查看术语 | 保留已有文件状态和批量失败汇总；原生列表及确认防误删 |
| 术语编辑 sheet | 保存／取消；文本字段与启用状态 | 保留原生表单及人工条目优先，不改变资料语义 |
| 资料预览 | 文本预览／关闭；打开原文件 | 保留提取文本的滚动预览；打开原文件调用系统应用 |
| 全部设置 | 两套配色／恢复默认；模型、记录细节、音频、浮窗、存储 | 原生分组表单，窗口可适配；主题底色与状态色统一，无新增深浅开关 |
| 后台队列 | 暂停／继续／重试；任务面板另有取消 | 保留列表、进度及已有任务语义，不因前端优化改变调度 |
| 废纸篓 | 恢复；永久清空为危险操作 | 保留原生列表、预览统计与二次确认，不演示删除真实资料 |
| 新建／重命名 sheet | 右下创建／保存与取消 | 保留 Return 提交、Esc 取消、空名称禁用；不另造自定义控件 |
| 导入／导出文件面板 | 系统选择／取消 | 保留 AppKit 文件面板、受管副本与原目录保护 |
| 归档／取消处理／错误确认 | 原生确认和可恢复说明 | 保留危险角色、文字后果及取消入口；错误内容不截断 |
| 退出确认／保存进度／失败 | 等待／取消退出／失败确认 | 保留 AppKit 保存流程、状态与取消，不改变收尾边界 |
| 应用菜单／菜单栏入口 | 开始暂停、结束、打开主窗／浮窗、退出 | 保留快捷键及用户现有路径，不创建新页面 |

## 基线验收记录（新候选以本轮记录为准）

- 56 项原生测试、20 项复核／书签后台契约、4 类退出探针通过。完整隔离应用回归通过。
- 实际按钮／菜单事件已验证：课程→讲次、开始新 Lecture、录制中设置配色／恢复默认、暂停／继续／结束、
  搜索输入／无结果／清除、A+ 到 28 点、浮窗入口、书签与优先复核入口、回听、接受／忽略／撤销、Esc 关闭。
  最新锁屏期间事件直接发送给本地原生窗口，不能替代系统桌面焦点和硬件输入验收。
- 录制使用静音 PCM，经真实 CapturePump／写盘／封存／登记；暂停继续后仍一段文件。字幕与中文回填是
  明确的合成事件；课后文字与候选是夹具，不验证模型、翻译质量或真实课件增益。
- 配色控件真实点击并另启进程验证持久化，预览最终恢复冰蓝；切换配色阅读偏移保持 36 点。
- 原先结束按钮空心区域点击后仍 running，补 contentShape 后相同坐标立即 ended，并封存一段文件。
  双语开课原先误进课后页，现进入实时；关闭复习窗口原先仍回听，现 Esc 后立即停止，迟到详情不重启。
- 主窗 740／1080 点、正文最大 28 点、复核 410×320、浮窗 320 点宽／56 点字进行了运行界面检查。
  本轮前期真实截图与后期 AppKit 内容渲染分别保存；最后的白色背板合成截图受锁屏阻挡，未标通过。
- 浮窗两主题最低透明度的旧英文计算对比度约 6.08／5.73，属于色值计算；未完成屏幕像素测量。
  减少动态效果走预览注入分支；英文／中文事件确实更新，停止跟随后偏移 20→20。
  浮窗显示保持同一应用的 key window；外部幻灯片应用／全屏空间焦点仍待实测。
- 既有深色与高对比语义色覆盖原生计算测试，深色窗口做了截图／渲染兼容检查；没有新增深色主题开关。
  未对操作系统高对比设置、减少透明度或 VoiceOver 做完整全流程实测。
- 原生辅助功能树目前只取得部分节点；之前解锁时 Tab 可达搜索／列表且焦点环可见。
  系统全键盘访问关闭；最新锁屏状态 active=false。不能标所有按钮 Tab 遍历和系统焦点通过。

逐屏验证层级：课程／讲次、采集、实时搜索／字号、浮窗、书签、优先复核及配色设置有入口事件测试；
空态、暂停／结束、异常、旧深色、课后结果有运行窗口与合成状态检查；设置下方各组做代码审查，
并未逐个修改设备／存储选项。资料、术语、段落编辑、队列、废纸篓、重命名、文件面板及危险确认保留既有
原生结构，本轮以代码核对为主，没有把危险操作或真实文件导入标为已测。退出边界单独使用原生探针验证。

可复现动效步骤：在隔离预览打开合成 Lecture，展开／恢复字幕、收起／展开侧栏，观察只在用户操作时过渡；
在停止跟随后补入同段中文，正文不逐条动画。系统减少动态效果的最终人工复验还需在解锁桌面进行。
