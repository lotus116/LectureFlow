# 实时识别、回改与正常退出

对应 SD-04/05/07/08、LF-02/03/04/11。本页为 0.6.3 当前实现；[PRODUCT](../PRODUCT.md)约束行为，[STATUS](../STATUS.md)维护验证与缺口。新口音原音复核不是本页已实现功能。

## 控制与保存

| 录音 | 英文输出 | 中文输出 | 当前路由 |
|---|---|---|---|
| 关 | 关 | 关 | 不采集 |
| 开 | 关 | 关 | 只录音，不加载推理模型 |
| 关 | 开 | 关 | 识别并保存英文，无音频 |
| 关 | 关 | 开 | 内部识别＋翻译，仅保存中文 |
| 开 | 开 | 关 | 录音＋英文 |
| 开 | 关 | 开 | 录音＋中文，英文不落库 |
| 关 | 开 | 开 | 双语字幕，无音频 |
| 开 | 开 | 开 | 录音＋双语字幕 |

英文关闭时当前字幕与修订历史均遵守保存边界，不把原文藏入元数据。模型未就绪且可保存音频时先录音，仅字幕模式不擅自写音频。暂停 softPause 不封存用户段，继续同段；结束／正常退出封存，之后继续录制追加新段。

## 音频与容量

AVAudioEngine 获授权后才初始化；tap 最多保留 32 个副本，转为 16kHz 单声道，录音和字幕分路。录音内部约五分钟一个 16-bit CAF 块；封存同步磁盘、记录哈希和 manifest 后登记。共享采集 ID、源起点与实际帧数保留时间映射；暂停块不作为独立用户录音行。

原生字幕管道最多八个待写音频包，Python InputBuffer 容量 240（控制消息也占位），常规包长 0.25 秒。持续超载仍可能丢字幕音频并计数；原音独立写入。磁盘写入失败／严重积压应明确停止采集，已有文件保留，不能把推理故障当录音必然丢失。

## 识别与句段边界

- 新会话／版本默认英语，快照记录 source_language 与 language_policy=2；开放自动检测需明确选择。已有记录保持原配置，缺失配置按英语处理，不把开放检测称中英限定。
- 流式 ASR 每约一秒更新，活动片段最多 12 秒；轻量能量端点使用估计噪声三倍，阈值限制 0.002–0.008，已在语音时乘 0.7 迟滞。
- 文本以完整标点结尾时停顿阈值 0.65 秒，否则 1.25 秒；保留前一包音频及尾部静音。能量阈值不能识别老师或确诊重复原因。
- 阅读层仅合并同会话相邻未完整短片段，间隔不超过 0.35 秒、最多三片段，保留源时间与修订；它不是新的 ASR 或精确句界保证。

## 必做中文回改与可选课件增强

稳定英文先保存，再为本段登记初译、为前两段登记带后文回改。同一目标合并最新的后两段依据，保留首次排队时间；真实前文最多 1200 字符，后文最多 1000 字符，可信译名按当前原句匹配，课程大纲不能冒充老师原话。

FIFO 每次服务一项，音频积压不超过两包或最老翻译等待至少六秒时执行；连续讲话也不取消必做回改。临时初译至少间隔一秒有调度机会，不保证一秒出字。移出最近三段窗口／停止／切换输出配置前完成相关待办再锁定；失败待办不伪装完成。

课件 polish 与中文回改分开：只留最新候选，空闲时最多每 20 秒一次；目标锁定／失效、无相关术语或改写门不接受时不应用。接受英文修订后重排本段和相关前文翻译。此单槽仍有 A05a 缺口，不能用来宣称已具备新原音复核的积压补做。

## 故障与正常退出

不以“文字没变化”判断卡死。已收到音频但无处理进展的期限随最长已完成单包推理耗时适应：min(600, max(180, 耗时×8)) 秒；初始准备允许 300 秒。内部 chunk 计数在累计收到超过四秒音频仍不前进时也报告异常。自动恢复最多三次，退避 2/4/8 秒，旧故障进程事件隔离；耗尽后不自动绕过上限，用户可暂停再继续。

正常暂停／结束接收原进程尾部事件，新进程等旧链路收尾。正常退出依次等待录音封存与异步登记、字幕 stopped 和实际子进程成功结束、本应用后台任务保存进度；不能仅收到 stopped 就退出。保存失败、异常 EOF／非零退出、剩余待办不算成功；允许取消退出，取消后不自动开麦。只等待本应用管理的进程。

主线程使用普通事件循环完成回调，避免 terminateLater 嵌套等待阻塞保存；重复退出不创建重复收尾。系统注销／重启若先被保护拦下，保存退出后需再操作。强杀／断电与模型持续失败不是正常排空，实时内存待办尚无跨进程恢复（A01b）。

## 诊断与证据

本地 live-health 数值诊断记录输入／处理时间、耗时、积压、丢包与恢复，当前会话最多 64 个缺口；不记课堂文字、音频或任意模型 stderr。只录字幕没有原音时，已丢音频无法课后补回。
