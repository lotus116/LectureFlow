# 待讨论的具体方案

本页是方案，不是已批准的执行清单。当前任务先完成文档整理；回到功能开发前，以 [STATUS](../STATUS.md) 的批准状态为准。已有需求缺口不会因暂缓而删除。

## 口音增强讨论暂停点

用户已确定先讨论口音原音复核，且口音增强、按课程追踪老师、人声分离要分别可开关以便 debug。现在没有实施批准。老师自动追踪不要求强制注册；不同课程老师和环境不同，邻座可同时说话且更响。保留原音，课堂优先改善字幕，下课后可选老师轨。资料增强重设计另留下一版本。

以下只是最近一轮助手建议，均待确认，不是已验证算法：

| 讨论项 | 候选设计 | 仍需确认／验证 |
|---|---|---|
| 触发 | 稳定片段登记待办，等约 3–5 秒后文，最多 30 秒原音；争议片段最多再看一轮新后文 | 时机、窗口、次数与算力成本未冻结 |
| 接受改写 | 目标片段重新解码与相邻原音解码对照，不把一个答案喂给另一次；可靠对齐后才考虑局部修改 | 同模型会共同犯错，一致不是正确概率；缺少校准置信度 |
| 防止改坏 | 数字／否定／比较关系、大范围变更和歧义对齐先留候选；最多两处、约 20% 修改是初始建议 | 不能仅凭通顺、专业词存在或小改动判断正确；短句需另验 |
| 积压 | 独立可追踪队列；初译与现有中文回改优先；以约 0.5 秒音频积压作为候选执行门槛；同目标合并不重置等待时间 | 新队列与现有课件单槽不同；持久化、停止与恢复需要方案批准及行为测试 |
| 过窗结果 | 仍在最近 1–3 句时可回改；过窗结果放入可查看的增强修订版本 | 版本展示、锁定语义与用户阅读体验尚未确认 |
| 仅字幕模式 | 候选只在内存保留约两分钟原音，不偷偷写盘；超出可恢复范围明确未完成 | 缓存与隐私边界、退出后补做能力须确认，不能保证永远补齐 |
| 开关 | 三个方向独立；候选为默认关闭、记住选择，记录配置；分离无老师参考时提示条件不足 | “独立开关”已要求；默认值、在途任务处理、依赖与切换生效点仍待定 |
| 验证 | 先仅生成候选，不改变字幕；人工盲核原错→改对、原对→改错、关键字风险和延迟 | 需人工真值，不能用模型自评代替；未承诺零误改 |

固定英语及现有必做中文上下文回改不能因新增开关被关闭。英文自动修订与中文提交需版本一致；人工编辑和新版本不能被旧任务覆盖。这些保护目标不等于已实现队列。[实验数据与限制](../research/SPEECH_RESEARCH-2026-11-05.md)。

## 其余偏差的具体讨论方案（尚未批准实施）

下列是 2026-11-04 提出的具体修复方案，未因文档整理获得批准。旧建议顺序不覆盖用户当前先讨论口音的方向；可分别讨论，不捆绑。

| 事项 | 拟实施的用户行为与调度 | 保护规则与验收 |
|---|---|---|
| A05a 课件辅助识别补做 | 把每段已选中相关术语的二次识别登记为可追踪任务；先出普通识别与初译，积压后按最早等待时间补做，保留后文回改。未命中相关术语的段落无需增加推理。替代当前“每 20 秒、只留最新”的丢弃策略。 | 原音和原始识别保留；只有满足既有证据门槛才采用改写。明确展示未完成数；测试连续讲话、积压与停止排空，核对否定词／术语污染。持续算力不足时会更慢，不能承诺只靠调度解决；是否保存待办跨重启需同时确认。 |
| A05b 资料替换与实时生效 | 增加“重新处理／替换新版”；旧版继续有效，新版处理成功才原子切换，失败保留旧版。新词表在下一个语音片段边界生效并提示。 | 人工术语优先；旧课后任务保留创建时快照；旧转写不自动整堂重跑。测试替换失败、重复导入、采集中更新、人工改词冲突。 |
| A02 课后跨段上下文 | 新课后版本先保存逐段原始识别，再用前后相邻片段翻译；末尾没有后文时正常完成。任务显示识别／翻译进度，断点恢复分别从各自已提交位置继续。 | 不覆盖旧版本和人工编辑；只重试尚未成功步骤。测试跨 30 秒边界的指代／术语、暂停重启及片段顺序变化；用用户指定误译片段人工比较效果。 |
| A03a 实时编辑与恢复 | 为实时记录增加逐段编辑、恢复原文、显式单段重译；人工修改存独立覆盖层，后台回改仍保存历史但不覆盖人工显示。 | 编辑中的段落不被新事件替换；重译生成可恢复修订，不默默抹除手工译文。测试并发回改、恢复、重复重译及仅中文保存模式。 |
| A03b 定位播放与统一导出 | 有原录音的段落提供定位播放，暂停间隙按既有源映射定位；实时／课后均提供 TXT、MD、SRT、JSON 与当前语言选择。 | 没有音频不显示播放；不泄露未保存的英文；导出包含当前人工结果并保留版本来源。核对跨暂停块、语言筛选、字幕时间及历史版本。 |
| A04 批量资料失败隔离 | 一个文件失败仍继续处理其他文件；结束汇总成功／失败文件，支持只重试失败项。 | 去重不误报为失败，不重复创建成功条目；用成功—损坏—成功三文件序列验证。 |
| A06 悬浮历史阅读 | 上滚或拖动后冻结当前阅读位置，保留有界历史，提供“返回最新”；新字幕到达不挤走正在看的内容。 | 不改变保存方式。默认显示建议沿用当前仅中文，是否改双语由用户确认；测试滚轮、触控板、字号和 1–6 行切换。 |
| A07 单段语言一致性 | 单段与整堂任务统一读取当前语言偏好并写入任务快照；新安装继续默认英语，主动选实验自动才启用。 | 不改已有任务或录音；分别测试两种入口、默认英语和显式自动、重启恢复。 |
| A08 名称与冲突操作 | 先增加纯显示名称字段，采集中改名不搬动真实文件夹；需要移动／删除时列出冲突任务，允许取消操作或明确取消相关任务后继续。 | 不去掉保护锁；历史路径／时间映射保持有效。核对活跃采集、后台任务、失败回滚和废纸篓恢复。 |
| A01b 异常强杀后补做 | 另建持久化待办，原文、上下文版本和翻译提交在事务中记录；下次启动提示恢复待办，不自动开麦。 | 明确仅字幕／不保存英文时可持久化哪些内容，需用户确认隐私范围；测试在提交前后强杀、重复恢复和人工修改冲突。正常退出修复不代表此项已实现。 |

真实课堂中用户自己试用属于反馈流程；先记录版本、问题时间和预期，复现后再判断是缺陷修复还是需要调整需求。只有用户确认的新产品决定才写入设计基线，发现偏差不会靠修改 PRD 将其“消除”。


## 其他保留缺口

- SD-01：Lecture 日期独立展示缺口保留，未自行调整导航。
- 质量：原始模型基线、真实资料增强、人工中文语义、语义延迟与长时／硬件门槛仍见 STATUS；一轮离线研究不关闭这些门槛。
- 资料增强用户反馈：专业词听错会连带中英文出错，且无法看出导入资料是否生效；课程大体跟课件、偶尔补充或跳页。重设计仍延期，不能将“自动跟页”当已批准方案。
