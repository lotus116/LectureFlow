# macOS 两套可选配色与原生阅读界面

2026-11-28 用户授权全面优化 macOS 前端，随后明确由 Codex 直接完成设计与实现，不再等待外部模型。
默认保留既有冰蓝；第二套采用暖石白／墨绿，适合长时间阅读。两套均以浅色主窗验收，
保留原有深底字幕浮窗及已有外观适配，不新增系统／浅色／深色开关。没有外部模型意见被用于本轮实现。

基线为 [首轮前端记录](FRONTEND-2026-11-28.md) 和
[实时隔离／课后复核](../research/MAC-LIVE-ISOLATION-2026-11-28.md) 的未提交主工作树。
本轮仅改前端；原音、人工编辑、模型、实时初译、必做回改、翻译时序与复核数据含义不变。
没有推送、发布、覆盖安装、访问中转服务或改 Windows／Android。

## 颜色与组件

- 设置同时展示冰蓝与暖石白／墨绿，并提供恢复默认。`colorTheme` 只保存配色；缺失或未知值按冰蓝显示，
  不迁移旧用户偏好。切换不使用 `.id` 重建页面，不重置采集或阅读位置。
- [Theme.swift](../../native/Sources/LectureFlow/Theme.swift) 集中语义色，`LFChrome` 集中字级、行宽、间距与动效。
  颜色区分背景、面板、正文、中文、强调填充与强调文字；录制红不随主题改变含义，状态仍有文字与图形。
- 暖石主背景 `#F8F6F0`、侧栏 `#EBEEE5`、面板 `#FFFEFA`、强调 `#24634E`、强调文字 `#205840`；
  冰蓝原主背景 `#F8FBFF`、侧栏 `#EEF5FC`、强调 `#2563EB` 保留。
- 小字号已标记书签使用强调文字色。冰蓝从系统蓝的计算对比度 3.52:1 提升为 6.70:1；墨绿为 8.22:1。
- 浮窗保留透明度 0.2–1 的偏好范围，外围仍可透出课件；工具栏与正文加 0.86 深色局部衬底。
  按最小透明度、纯白背板、旧行 0.72 与英文 0.85 叠加计算，最弱正文约为冰蓝 6.08:1、墨绿 5.73:1。
  **这是 sRGB 色值合成计算，不是屏幕实拍取色结果。** 高对比度或减少透明度仍使用不透明底色。
- 字幕追加／中文回填不做逐次动画；用户展开／收起和侧栏使用 160 ms，尊重减少动态效果。

完整界面与控件位置、大小、保留理由见 [逐屏核对](UI-SURFACES-2026-11-28.md)。
