# 视觉与资源

当前已确认的是琪露诺冰蓝主题与录音岛，取代早期暖白绿。应用操作行为以 [PRODUCT](../PRODUCT.md)为准；本页不重新授权旧 UI 任务书。

- 录制／暂停：横向电平波形、大计时、暂停与结束；结束后紧凑保存状态和继续入口。
- 主窗口有展开字幕／恢复布局、可调字号；课程侧栏可折叠，录音列表连续行、友好名称与本地时间，源名仍可追溯。
- 主窗口默认内容尺寸 1080×700、侧栏默认宽 220 点、紧凑宽度下为 200 点，可拖动调整，系统可恢复此前窗口状态；悬浮窗与主窗口显示偏好独立。默认语言差异保留 A06，不在文档整理中选定新值。
- 根 README 使用正式版图标与功能示意图；早期同人视觉留在历史记录中。
