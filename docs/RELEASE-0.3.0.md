# LectureFlow 0.3.0 · 使用反馈改进

- **更紧凑的课堂空间**：收紧侧栏、工具栏与录音行，按当前页面显示任务信息。
- **独立悬浮字幕**：开启实时模式可自动显示；独立选课、开始与暂停、字号和双语设置；主窗口可隐藏或关闭，菜单栏随时找回。
- **重整知识库**：默认合并本课与课程共享资料；页码大纲、定义、缩写、来源可查；课件拼写自动用于实时和离线识别，近期讲话帮助选择相关页面术语。
- **批量中英文术语管理**：搜索、多选、采用、忽略、编辑与本地中文补全。后台补全可暂停、取消、重试和续办，人工中文优先，模型建议需校对。
- **废纸篓可清空**：预览数量与大小，再确认永久清理；中断可继续收尾。修复切换课堂时旧转写残留及过期读取覆盖的问题，检查同名课程的数据隔离。

Apple Silicon · macOS 26+ · 建议 16 GB 内存。下载 ZIP，解压后将 LectureFlow.app 拖入“应用程序”。更新前暂停并退出旧版；首次升级索引会备份原数据库，已有资料与模型继续使用。

运行环境随包附带，模型不打包；首次自动后台下载约 1.86 GB，可暂停和继续。本机识别、翻译与课件解析；云端总结仍需明确预览和确认。

已检查构建、必要功能和数据保护。识别质量、课件增益、延迟、续航与三小时连续使用仍待实际反馈，不代表已通过评估。当前应用使用本地签名，尚未 Apple 公证。
