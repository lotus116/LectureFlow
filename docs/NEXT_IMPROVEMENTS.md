# 下一阶段讨论稿 · 2026-10-31

状态：建议，尚未确认为实现范围；不把上游模型能力计为产品支持。

## 建议顺序

1. 明确讲话语言与目标语言，解除当前 `language="English"` 和简体中文翻译指令的固定设置。先覆盖实际使用的少数语言，再扩展。
2. 识别与翻译独立选择模型；对同一短片段生成可比较的新版本，保留原识别及人工修改。较大模型仅作候选，优势须实测。
3. 可选语音增强，先验证真实噪声片段是否减少识别错误；默认关闭，不承诺改善口音。

## 重口音

- 区分噪声、混响、音量过低、截断和口音导致的识别错误。
- 优先提供正确的语言设置、合适的模型和保留上下文的分段；相关术语仅辅助拼写，不按课件重写原话。
- 如果用户愿意提供本地片段，可用同一批短片段比较标准／较大模型，以及原音／增强输入。主要看人工核对的错词、漏句、否定词和术语，另外记录处理耗时。
- 不把“修正错字”描述成模型已经学习了老师的口音；个性化微调需要额外数据和验证，暂不优先。

## 多语种与模型选择

- 源语言：明确语言或自动检测；目标语言单独设置；混合语言另行验证，避免逐句不稳定切换。
- 模型项显示已安装状态、支持语言、下载与资源要求；未知的速度或质量不写成优势。
- 活跃采集须先暂停再切模型；源录音写入独立于识别、翻译及增强。
- 任务持久化源／目标语言、模型标识与修订、增强配置；旧任务恢复保持原配置，不静默更换模型。
- 课程可保存偏好，Lecture 或新任务允许覆盖；已有转写仅在用户主动生成新版本时改变。

## 增强处理边界

- 原录音保持不变，仅对推理输入处理；不让增强阻塞录音，不静默丢帧。
- 保持原始时间轴和采样映射，补偿算法延迟；失败时明确回退并记录配置。
- 只在测试证据支持的场景推荐启用。声音听起来更干净不等于识别更准。
