# 开发者审查 · 2026-10-30

本文保留早期审查记录，后续交付分别列于 0.2、0.3 节。主开发者自审，模型质量与长时验收仍待实际使用。

## 已修复

1. 审查发现报告输出路径可与源录音相同，从而在裁剪前覆盖源文件。两个入口现已在写入前拒绝相同路径，增加源文件字节不变回归测试。
2. 单独的进程 RSS 不完整反映 Metal 内存。加入 MLX 活跃、缓存和峰值指标，明确不将两者简单相加作为总内存。
3. 流式计时使用固定音频可用时间，避免因推理变慢而推迟播放时钟、掩盖积压。
4. 质量与实时延迟未验证时明确标为未评估；没有参考英文不生成 WER；离线吞吐不当作初译语义延迟。
5. 导入和导出目录增加符号链接边界检查，避免受管子目录指向资料库之外；增加回归测试。
6. 转写与检查点同事务提交；版本读取使用一致性快照，避免导出读到混合时刻的数据。
7. worker 使用 OS 独占锁，只有取得锁后才能恢复中断任务；暂停/取消时不提交仍在推理的区间。
8. 任务保存模型固定提交，恢复时拒绝静默更换模型；录音内容变动时在推理前拒绝继续。
9. 检查发行包发现 MLX 当前固定版本要求 macOS 26，已修正 README、安装器与应用系统要求。
10. 实时输入采用有界缓冲；录音队列不写推理管道。破裂管道设置 NOSIGPIPE 并加入回归测试，避免子进程异常终止录音应用。
11. 重采样停止时刷新尾部再封存 CAF；分块边界逐帧验证，封存时同步磁盘。恢复不触碰活动录音，保留无法解码的块并标明部分恢复。
12. 增加共享采集 ID 与源起点；录音 manifest 可关联实时字幕会话，停止与恢复不混淆课堂身份。
13. 麦克风引擎改为授权后延迟初始化；字幕子进程失败时保留录音开关，无采集功能时停止麦克风。

## 保留风险

- 虽已处理完整长录音，部分术语错误仍存在，缺少人工参考，不能声称课堂准确率达标或确定最终模型。
- 翻译运行时提示 Transformers 对 RoPE 配置字段的元数据警告。MLX 架构可加载和生成，但官方输出对照尚未完成。
- 流式探针采用受限窗口和串行流程，尚无完整句子修订策略，跨窗口中文不代表完整课堂转写。
- 实时三开关与分块存储已实现，但真实麦克风授权/设备采集、三小时实时运行、睡眠和设备故障未验收；本轮 UI 工具无法取得窗口。
- 当前采用轻量能量端点和最长约 12 秒语音片段；句界、低音量、噪声、口音及修订质量需要进一步实测。字幕缓冲溢出会提示，但缺口的持久化标注仍待完善。
- 文件与 SQLite 跨介质无法在同一事务原子提交；异常崩溃可能留下未索引的导入副本，但不会修改原录音。尚需恢复扫描功能。
- 开发版应用依赖本机项目环境，尚未制作独立发行包。
- 严格离线状态尚需网络隔离下验证；目前已实施默认离线与本地快照加载，无云端推理调用。

## 0.2.0 可上手版本审查

需求：LF-01–12 的代码交付；人工效果、延迟、续航与长时评估由用户暂缓。

重点检查并修正：

- 文件操作先持久化移动意图，物理移动后同步目录，再提交索引；启动恢复未完成意图。删除使用本地可恢复废纸篓；历史片段 ID 和源时间锚点保留。
- 录音复制不将原课堂误标为过期；移动、删除与资料变化使受影响结果过期。
- 后台 worker 已持有互斥锁时允许恢复自己的文件日志，避免错误地跳过恢复。
- 取消当前录音先封存并校验目录身份，再移入废纸篓；字幕处理独立继续。应用重新打开时登记遗留录音。
- 总结仅发送预览摘要匹配的材料；重试显示原任务材料；拒绝重定向；密钥不进入命令参数、数据库、输出或日志。旧转写生成的新总结仍提示来源过期。
- 独立应用移除开发目录依赖；模型下载与缓存独立，退出时停止本次下载，缓存供下次继续；发布不包含课堂资料。

功能证据：64 项 Python 与 8 项原生测试、原生/Release 构建和独立运行环境检查。真实麦克风与模型效果不计为已验收；限制列于 STATUS 和 USER_GUIDE。

## 0.3.0 使用反馈审查

需求：LF-01、05、06、07、08、09、11；用户反馈四项问题。代码范围与操作见 FEEDBACK-0.3 和 USER_GUIDE。

- 同名课程的数据库与文件夹原本使用 UUID；本轮发现主界面旧转写残留、异步返回未核对课堂，以及旧实时历史未立即清空。加入选择代次、课堂/版本双重校验、请求顺序检查和立即重置；界面内部资料状态按课堂隔离。
- 永久清理使用预览摘要绑定当前废纸篓范围，明确确认后写入持久化意图；数据库提交后仅删除受控废纸篓路径，启动继续未完清理。不按课程名称定位；已转移到正常课程的资料保留，不跟随外部符号链接。
- 清空课堂同时删除关联记录；只清空录音保留完成文本、标明源缺失并取消无法继续的未完成任务。活动录音、模型工作和总结任务有互斥保护；真实用户资料未用于清空测试。
- 课件处理保留页码与原文件；自动识别提示只选有来源的高置信度拼写，长度和数量有界，不把全文直接作为 ASR 输出。原始英文不强制改写，版本保存独立资料快照。
- 术语批量操作核对拥有者，合并管理仅允许本课堂与其实际父课程；不能修改同名其他课程。文件夹移动与课件修改互斥；本地中文补全按术语持久化进度，取消不提交未完成项，人工修改优先；新音频与实时请求优先让出模型。
- 主窗口生命周期与后台监控分离；浮窗包含独立控制，关闭主窗口不退出应用，菜单栏与 Dock 可找回。没有新增云端推理或付费调用。
- 旧索引升级前自动备份；新增嵌套事务支持，确保旧课件在首次转写时建立索引后使用同一最新修订号。

本机证据：83 项 Python、10 项原生测试及 Release 打包通过。UI 使用合成资料隔离检查；用户随后自行开启字幕试用。课件准确率增益、跨全屏/多显示器全部组合、设备故障与三小时表现没有作为通过项。

独立包运行环境的索引、课件提示、同名隔离和清空检查通过；PR #3、主分支与发布检查通过，0.3.0 已公开发布。链接与校验和见 STATUS。

## 0.4.0 课堂流程与识别污染修复

- 上一版将多达 70 个课件词直接作为识别 context，这个设计可能使生成模型复述词库。0.3 的数据流测试没有验证这种真实模型行为；本轮不以那些测试声称质量安全。
- 撤销生产识别提示路径：实时与离线识别传空 context，旧任务恢复也不读取旧词表作为输入；删除未再使用的拼写提示生成函数。翻译不再收到整页课件、整张词库或前一段原文作为翻译上下文，只匹配当前原句中的少量已采用术语。保留真实识别词，不按词表盲删输出。
- 使用会复述任何输入前缀的替代模型做回归检查，验证旧 context、课件和词表均不进入识别；静音不产生实时字幕；旧污染版本原样保留，新结果独立版本，并提示重新转写。
- 课堂生命周期独立于写入器/推理进程：计时排除暂停，继续保留方式，结束后重新开始重置本次采集；本机检查点恢复为暂停，不自动打开麦克风。缺模型时不擅自启用原始录音。
- 模型请求与实际加载分离，启动期间改选不会被旧 ready 覆盖；选择改回时仍跟踪延迟确认；原生会话创建先核对代次再赋值，避免迟到结果覆盖新会话。
- UI 检查发现系统自动侧栏项仍可能重复插入，改为应用自己管理分栏和唯一导航按钮；已检查隐藏/展开位置。录音方式、高级开关、模型下载和后台任务有明确入口，暂停/结束不等待推理。
- 输入音量按真实 PCM 更新并限制频率，不让音量刷新驱动整份资料库重绘；不新增云端服务或自动总结。

证据：89 项 Python、19 项原生测试和开发构建通过；模型选择、记录方式和侧栏位置已用合成资料界面检查。模型准确率、真实麦克风故障与三小时表现继续暂缓。

0.4.1：替换分栏时漏掉详情的顶端布局约束，低内容高度会导致父容器整体居中。增加外层详情、课堂容器与填满剩余高度的内容区三层顶部约束。已逐页检查空内容和已有内容的录音、转写、实时、知识库、笔记，顶部控制与页签位置稳定；界面测试只用合成数据。
