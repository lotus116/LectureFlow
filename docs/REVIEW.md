# 开发者审查 · 2026-10-30

范围：模型验证、资料库、离线 worker、实时基础、导出及 SwiftUI 开发版。主开发者自审；尚无独立审查或正式发布验收。

## 已修复

1. 审查发现报告输出路径可与源录音相同，从而在裁剪前覆盖源文件。两个入口现已在写入前拒绝相同路径，增加源文件字节不变回归测试。
2. 单独的进程 RSS 不完整反映 Metal 内存。加入 MLX 活跃、缓存和峰值指标，明确不将两者简单相加作为总内存。
3. 流式计时使用固定音频可用时间，避免因推理变慢而推迟播放时钟、掩盖积压。
4. 质量与实时延迟未验证时明确标为未评估；没有参考英文不生成 WER；离线吞吐不当作初译语义延迟。
5. 导入和导出目录增加符号链接边界检查，避免受管子目录指向资料库之外；增加回归测试。
6. 转写与检查点同事务提交；版本读取使用一致性快照，避免导出读到混合时刻的数据。
7. worker 使用 OS 独占锁，只有取得锁后才能恢复中断任务；暂停/取消时不提交仍在推理的区间。
8. 任务保存模型固定提交，恢复时拒绝静默更换模型；录音内容变动时在推理前拒绝继续。
9. 检查发行包发现 MLX 当前固定版本要求 macOS 26，已修正 README、安装器与应用系统要求。
10. 实时输入采用有界缓冲；录音队列不写推理管道。破裂管道设置 NOSIGPIPE 并加入回归测试，避免子进程异常终止录音应用。
11. 重采样停止时刷新尾部再封存 CAF；分块边界逐帧验证，封存时同步磁盘。恢复不触碰活动录音，保留无法解码的块并标明部分恢复。
12. 增加共享采集 ID 与源起点；录音 manifest 可关联实时字幕会话，停止与恢复不混淆课堂身份。
13. 麦克风引擎改为授权后延迟初始化；字幕子进程失败时保留录音开关，无采集功能时停止麦克风。

## 验证证据

- `zsh scripts/dev`：固定依赖检查、代码检查和行为测试，结果见 STATUS。
- 49 个 Python 测试和 7 个原生测试覆盖离线工作流与实时路由、保存、修订、迁移、恢复和模型让出。
- 完全不安装模型或 MLX 的独立环境中，Python 测试通过；原生应用与原生测试构建通过。
- 真实三段录音共约 176 分钟，353 个区间完成，双语文件均已导出，逻辑时间轴连续且保留片段原始时间。
- 原生 UI 实测：搜索生效；高精度单段任务在 1/15 暂停，恢复后关闭窗口，后台继续至 15/15；重新打开窗口可见结果。
- 真实 M4A 基准与流式探针保留于 `reports/private/`，均未上传。
- 已完成的源文件校验：三份录音 SHA-256 与测试前相同。
- 实时双语与只翻译协议分别回放 30 秒真实录音成功；无输入队列丢包，资料库未保存音频，只翻译时未保存英文及英文修订。

## 保留风险

- 虽已处理完整长录音，部分术语错误仍存在，缺少人工参考，不能声称课堂准确率达标或确定最终模型。
- 翻译运行时提示 Transformers 对 RoPE 配置字段的元数据警告。MLX 架构可加载和生成，但官方输出对照尚未完成。
- 流式探针采用受限窗口和串行流程，尚无完整句子修订策略，跨窗口中文不代表完整课堂转写。
- 实时三开关与分块存储已实现，但真实麦克风授权/设备采集、三小时实时运行、睡眠和设备故障未验收；本轮 UI 工具无法取得窗口。
- 当前采用轻量能量端点和最长约 12 秒语音片段；句界、低音量、噪声、口音及修订质量需要进一步实测。字幕缓冲溢出会提示，但缺口的持久化标注仍待完善。
- 文件与 SQLite 跨介质无法在同一事务原子提交；异常崩溃可能留下未索引的导入副本，但不会修改原录音。尚需恢复扫描功能。
- 开发版应用依赖本机项目环境，尚未制作独立发行包。
- 严格离线状态尚需网络隔离下验证；目前已实施默认离线与本地快照加载，无云端推理调用。

## 0.2.0 可上手版本审查

需求：LF-01–12 的代码交付；人工效果、延迟、续航与长时评估由用户暂缓。

重点检查并修正：

- 文件操作先持久化移动意图，物理移动后同步目录，再提交索引；启动恢复未完成意图。删除使用本地可恢复废纸篓；历史片段 ID 和源时间锚点保留。
- 录音复制不将原课堂误标为过期；移动、删除与资料变化使受影响结果过期。
- 后台 worker 已持有互斥锁时允许恢复自己的文件日志，避免错误地跳过恢复。
- 取消当前录音先封存并校验目录身份，再移入废纸篓；字幕处理独立继续。应用重新打开时登记遗留录音。
- 总结仅发送预览摘要匹配的材料；重试显示原任务材料；拒绝重定向；密钥不进入命令参数、数据库、输出或日志。旧转写生成的新总结仍提示来源过期。
- 独立应用移除开发目录依赖；模型下载与缓存独立，退出时停止本次下载，缓存供下次继续；发布不包含课堂资料。

功能证据：64 项 Python 与 8 项原生测试、原生/Release 构建和独立运行环境检查。真实麦克风与模型效果不计为已验收；限制列于 STATUS 和 USER_GUIDE。
